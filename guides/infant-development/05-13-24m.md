# 05. 13~24개월 — 걷기, 어휘 폭발, 자율성

가장 극적인 변화의 해입니다. 걷고, 말하고, "싫어"를 배웁니다. 부모 입장에서는 **처음으로 훈육이 필요해지는 시기**이며, 여기서의 대응 방식이 이후 몇 년의 패턴을 만듭니다.

**한 줄 요약: 아이는 지금 반항하는 게 아니라, 자기가 독립된 사람이라는 걸 처음 발견한 겁니다.**

---

## 1. 발달 이정표 (CDC 2022 · 약 75% 기준)

### 15개월
| 영역 | 이정표 |
|------|--------|
| 사회·정서 | 관심을 끌려고 물건을 보여준다 · 좋아하는 것에 손뼉을 친다 · 안아준다 |
| 언어 | **"마마"/"아빠" 외에 의미 있는 낱말 1~3개** · 아는 물건을 가리켜 요구한다 · 간단한 지시를 따른다 |
| 인지 | **모방한다** (집안일 흉내) · 컵에 물건을 담는다 |
| 운동 | **몇 걸음 혼자 걷는다** · 손가락으로 음식을 먹는다 |

### 18개월
| 영역 | 이정표 |
|------|--------|
| 사회·정서 | **재미있는 것을 보여주려고 부모에게 가져온다** · 낯선 상황에서 부모에게 붙는다 |
| 언어 | **낱말 3개 이상** · 고개를 저어 "아니"를 표현 |
| 인지 | 도구를 목적에 맞게 쓴다(컵으로 마시기, 빗으로 빗기) · 낙서를 한다 |
| 운동 | **혼자 잘 걷는다** · 컵으로 마신다 · 숟가락을 쓴다 · 잡고 계단을 오른다 |

### 24개월
| 영역 | 이정표 |
|------|--------|
| 사회·정서 | 다른 아이가 있으면 **옆에서 함께 논다(병행놀이)** · 새 상황에서 부모 반응을 살핀다 |
| 언어 | **두 낱말을 붙여 말한다("엄마 가", "물 줘")** · 신체 부위를 가리킨다 · 낱말 최소 50개 내외 |
| 인지 | 두 단계 지시를 따른다 · 그림책의 사물 이름을 안다 |
| 운동 | 뛴다 · 공을 찬다 · 난간 잡고 계단 오르내리기 · 블록 4개 이상 쌓기 |

### 이 시기 핵심 지표: **24개월의 두 낱말 조합**
- 24개월에 **두 낱말 조합이 없거나, 표현 어휘가 50개 미만**이면 언어 평가를 권합니다.
- 한국어·영어를 함께 쓰는 이중 언어 환경이라도 **두 언어를 합친 총 어휘**로 판단하며, 이중 언어 자체가 언어 지연의 원인은 아닙니다. **[강함]**

## 2. 어휘 폭발 — 최대한 활용하기

18~24개월경 어휘가 급격히 늘어납니다(vocabulary spurt). 이 시기의 언어 입력이 이후 문해력·학업과 상관이 높습니다.

### 실전 기법
| 기법 | 방법 |
|------|------|
| **한 단어 더(+1 규칙)** | 아이가 한 단어로 말하면 두 단어로 되돌려준다. "차!" → "빨간 차!" |
| **선택지 주기** | "물 마실래?" 대신 "물 줄까, 우유 줄까?" — 단어를 쓰게 만든다 |
| **일부러 기다리기** | 원하는 걸 바로 주지 말고 **5초 기다린다.** 소리라도 내면 반응해준다 |
| **혼잣말 해설** | 부모가 자기 행동을 중계. "아빠는 지금 당근을 자르고 있어" |
| **책의 질문 늘리기** | "이게 뭐야?" → "얘는 지금 뭐 하고 있을까?" |

### 대화식 책읽기 (Dialogic Reading) — 근거가 확실한 방법 **[강함]**
Whitehurst의 방법으로, 여러 무작위 연구에서 표현 언어 향상이 확인되었습니다. **부모가 읽어주는 사람이 아니라 듣는 사람이 되는 것**이 핵심입니다.

**PEER 순서**
1. **P**rompt — 질문한다: "이게 뭐지?"
2. **E**valuate — 반응을 평가/인정: "맞아!"
3. **E**xpand — 확장: "그래, 큰 갈색 곰이네."
4. **R**epeat — 다시 말해보게 한다: "큰 곰이라고 해볼까?"

**CROWD 질문 유형**
- **C**ompletion 빈칸 채우기: "달님이 ○○을 했어요"
- **R**ecall 회상: "아까 곰이 어디 갔었지?"
- **O**pen-ended 열린 질문: "이 그림에서 무슨 일이 일어나고 있어?"
- **W**h- 질문: 누가/뭐/어디/왜
- **D**istancing 연결: "우리도 지난번에 동물원 갔었지?"

## 3. 자율성과 떼쓰기 — 이 시기의 본질

### 왜 이러는가
- **자율성 vs 수치심 단계(Erikson)**: 아이는 "내가 하는 것"을 확인하려 합니다. "싫어"는 반항이 아니라 **자아의 발견**입니다.
- **뇌의 구조적 한계**: 감정을 만드는 편도체는 이미 작동하지만, 그것을 억제하는 전전두엽은 **20대까지 미성숙**합니다. 두 살 아이에게 "참아"는 물리적으로 불가능한 요구입니다.
- 떼쓰기(tantrum)는 **18~36개월에 정상적으로 최고조**에 이릅니다.

### 떼쓰기 대응 4단계 (자세히: [08-discipline.md](08-discipline.md))
1. **안전 확보** — 위험한 물건 치우기. 다치지 않게만.
2. **감정에 이름 붙이기** — "블록이 안 돼서 화났구나." *(설득·설명·훈계는 지금 하지 않습니다. 안 들립니다.)*
3. **곁에 있기** — 말없이 앉아 있기. 안기려 하면 안아주고, 밀어내면 물러나 있기.
4. **진정된 뒤에 짧게** — "화날 수 있어. 그래도 던지는 건 안 돼." 한 문장이면 충분합니다.

### 떼쓰기를 줄이는 예방책 (대응보다 효과적)
- **배고픔·졸림 관리** — 떼쓰기의 절반 이상이 이 두 가지입니다. 외출은 낮잠·식사 시간을 피해서.
- **예고하기** — "5분 뒤에 나갈 거야" → "이제 두 번만 더 타고 가자" (숫자는 몰라도 예고 자체가 효과 있음)
- **선택지 주기** — "가자" 대신 "신발 신을래, 아빠가 신겨줄까?" 통제권을 조금 넘기면 저항이 줄어듭니다.
- **"안 돼"의 총량을 줄이기** — 환경을 바꿔서 금지할 일을 줄입니다. 만지면 안 되는 물건은 치우는 게 빠릅니다.
- **미리 규칙을 말하기** — 마트 도착 전에 "오늘은 과자 안 살 거야"를 미리.

### 하지 말아야 할 것
- **체벌** — AAP는 2018년 정책성명에서 체벌이 효과가 없고 공격성·정신건강 문제와 연관된다고 명시했습니다. **[강함]**
- **소리 지르기·모욕** — 신체 체벌과 유사한 부정적 결과와 연관.
- **떼쓸 때 요구를 들어주기** — 떼쓰기가 효과적인 수단이라고 학습시킵니다. 단, 이미 감정이 폭발한 뒤에 협상하지 말고, **애초에 요구를 예방**하세요.

## 4. 운동 발달과 놀이

### 대근육
- 걷기 → 뛰기 → 계단 → 공 차기 → 밀고 당기기
- **하루 최소 180분의 신체 활동**(WHO 권고, 1~4세). 시간을 몰아서가 아니라 하루 전반에 걸쳐.
- 실외 활동은 시력 발달(근시 예방)과도 관련이 보고됩니다. **[보통]**

### 소근육
- 크레용 낙서 (**굵은 크레용**, 쥐는 힘 연습)
- 블록 쌓기, 큰 퍼즐(1~4조각), 스티커 붙이기
- **실생활 참여**: 빨래 넣기, 물 붓기, 숟가락으로 옮기기 — 몬테소리식 practical life

### 놀이의 발달 단계
| 단계 | 시기 | 모습 |
|------|------|------|
| 혼자놀이 | ~2세 | 혼자 논다 |
| **방관자·병행놀이** | 2~3세 | **옆에서 각자 논다. 정상입니다.** 같이 놀지 않는다고 걱정할 필요 없음 |
| 연합놀이 | 3~4세 | 같은 활동을 하며 상호작용 |
| 협동놀이 | 4세~ | 역할을 나눠 함께 논다 |

### 상징놀이(가장놀이)의 시작
18~24개월경 블록을 자동차라고 하거나 인형에게 밥을 먹입니다. **이는 추상적 사고와 언어 발달의 중요한 지표**입니다. 부모가 함께 해주면 확장됩니다.

## 5. 수면 · 식사 · 배변

### 수면
- 필요량: **11~14시간**(낮잠 포함)
- 낮잠: 12~18개월경 2회 → 1회로 통합. 무리하게 앞당기지 말고 아이 신호를 따릅니다.
- **18개월 수면 퇴행**: 분리불안 재발, 걷기·말하기 급성장이 원인. 일과를 유지하며 지나갑니다.
- 침대 전환: 서둘러 유아침대로 옮길 필요 없습니다. **아기침대 난간을 넘기 시작하면** 그때가 신호입니다.

### 식사
- **편식은 정상 발달입니다.** 2~5세에 새로운 음식을 거부하는 것(food neophobia)은 진화적으로 정상입니다.
- **새 음식은 10~15회 이상 노출되어야 받아들여지기도 합니다.** 한두 번 거부했다고 포기하지 마세요. **[보통]**
- 강요·보상 금지: "다 먹으면 아이스크림"은 **채소에 대한 선호를 오히려 떨어뜨립니다.** **[보통]**
- 우유는 하루 약 500ml 이내. 과다하면 철분 결핍성 빈혈 위험.
- 주스는 권장하지 않으며, 준다면 만 1~3세 하루 120ml 이내(AAP).

### 배변 훈련 — 아직 서두르지 않기
- 대부분 **18~30개월 사이**에 준비되며, 여아가 다소 빠른 편입니다.
- **준비 신호** (모두 갖춰지면 시작):
  - [ ] 기저귀가 2시간 이상 마른 상태로 유지된다
  - [ ] 배변 전에 표정·자세로 신호를 보인다
  - [ ] 간단한 지시를 따를 수 있다
  - [ ] 바지를 스스로 내리고 올릴 수 있다
  - [ ] 변기·화장실에 관심을 보인다
- **너무 일찍 시작하면 전체 기간이 오히려 길어집니다.** 상세 방법은 [06-24-36m.md](06-24-36m.md).

## 6. 화면(스크린) 기준

- **18개월 미만: 영상통화 외 권장하지 않음**
- **18~24개월: 도입한다면 고품질 콘텐츠를 부모가 함께 보며 설명**해줄 것
- **2~5세: 하루 1시간 이내의 고품질 프로그램**, 가능한 함께 시청
- 식사 시간·잠들기 1시간 전·침실은 화면 없음
- **아이를 진정시키는 수단으로 화면을 쓰지 않습니다.** 스스로 감정을 조절하는 법을 배울 기회를 잃습니다. **[보통]**

## 7. 이 시기 준비물

**필요한 것**
- 굵은 크레용, 큰 도화지, 세척 가능한 물감
- 큰 블록(듀플로 계열), 3~6조각 퍼즐, 모양 맞추기
- 밀고 타는 장난감(라이드온), 공
- 유아용 식기(포크·숟가락), 미끄럼 방지 컵
- 실외용 신발, 안전모(자전거·킥보드 시작 시)
- 유아 변기 또는 변기 커버 + 발판 (준비 신호가 보일 때)
- **책장** — 표지가 보이게 꽂는 낮은 책장이 아이의 자발적 책 선택을 늘립니다

**여전히 사지 말 것**
- 학습 태블릿·전자 단어 카드 · 한글 학습지 · 조기 영어 DVD
- 소리·불빛이 요란한 전자 장난감 — **아이의 발화량과 부모-아이 상호작용을 오히려 줄인다는 연구가 있습니다.** 단순한 장난감이 낫습니다. **[보통]**

## 8. 24개월 자가 점검

- [ ] 혼자 잘 걷고, 뛰고, 계단을 오른다
- [ ] **두 낱말을 붙여 말한다**
- [ ] 사용하는 낱말이 50개 이상이다
- [ ] 신체 부위를 가리킬 수 있다
- [ ] 간단한 지시("공 가져와")를 따른다
- [ ] 인형에게 밥 먹이기 같은 **흉내내기 놀이**를 한다
- [ ] 다른 아이에게 관심을 보인다
- [ ] 블록 4개 이상을 쌓는다
- [ ] 낙서를 한다
- [ ] **영유아 건강검진 4차(18~24개월) 완료**
- [ ] **구강검진 1차(18~29개월) 완료**
- [ ] 18개월·24개월 **자폐 선별검사(M-CHAT-R/F)**를 받았다 ([10-checkups-vaccines.md](10-checkups-vaccines.md))
