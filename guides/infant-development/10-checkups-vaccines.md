# 10. 영유아 건강검진 · 예방접종 · 발달 선별검사

**"제대로 가고 있는지 확인하는 방법"**의 핵심 문서입니다. 한국은 국가가 무료 검진·접종 체계를 갖추고 있으므로, **이 일정만 놓치지 않아도 상당 부분의 조기 발견이 가능합니다.**

> ⚠️ **정책은 바뀝니다.** 아래는 정리용 기준표이며, 실제 일정은 반드시 아래에서 최신본을 확인하세요.
> - 예방접종: **예방접종도우미** nip.kdca.go.kr (질병관리청) — 자녀 등록 시 개인별 일정 자동 관리
> - 건강검진: **국민건강보험공단** nhis.or.kr / The건강보험 앱 — 대상 여부·검진기관 조회
> - 통합 육아정보: **아이사랑** childcare.go.kr

## 1. 영유아 건강검진 — 총 12회 (일반 8회 + 구강 4회), 전액 무료

### 일반 건강검진 8차

| 차수 | 시기 | 주요 항목 |
|------|------|-----------|
| **1차** | **생후 14~35일** | 문진·진찰, 신체계측, 건강교육(안전·수유·수면) |
| **2차** | 생후 4~6개월 | + **발달평가(K-DST) 시작**, 시청각 문진 |
| **3차** | 생후 9~12개월 | + 발달평가, 안전사고 예방 교육 |
| **4차** | 생후 18~24개월 | + 발달평가, **구강검진 1차 병행 시기** |
| **5차** | 생후 30~36개월 | + 발달평가 |
| **6차** | 생후 42~48개월 | + 발달평가, **시력검사** |
| **7차** | 생후 54~60개월 | + 발달평가, 시력·청력 |
| **8차** | 생후 66~71개월 | + 발달평가, 취학 전 준비 |

### 구강검진 4회

| 차수 | 시기 |
|------|------|
| 1차 | 생후 18~29개월 |
| 2차 | 생후 30~41개월 |
| 3차 | 생후 42~53개월 |
| 4차 | 생후 54~65개월 |

### 실무 팁
- **문진표는 미리 온라인으로 작성**하세요(건강보험공단 홈페이지/앱). 병원에서 급하게 쓰면 부정확해집니다.
- **해당 기간을 넘기면 무료 대상에서 제외**될 수 있습니다. 달력에 미리 넣어두세요.
- 1차는 신생아 시기라 놓치기 쉽습니다. **출산 전에 미리 표시**해두세요.
- 검진 기관은 지정 병원에서만 가능합니다. 다니는 소아과가 검진기관인지 미리 확인하세요.

## 2. K-DST — 한국 영유아 발달선별검사

### 무엇인가
**한국 영유아 발달선별검사(Korean Developmental Screening Test for Infants and Children)**. 건강검진 2차(생후 4개월)부터 8차(71개월)까지, **부모가 작성하는 문진표** 형식으로 발달을 선별합니다.

### 평가 영역 6가지
1. **대근육운동** — 앉기, 걷기, 뛰기
2. **소근육운동** — 잡기, 그리기
3. **인지** — 문제 해결, 이해
4. **언어** — 말하기, 알아듣기
5. **사회성** — 상호작용, 놀이
6. **자조** — 먹기, 입기, 배변 (18개월 이후 추가)

### 결과 해석
| 판정 | 의미 | 조치 |
|------|------|------|
| **빠른 수준** | 또래보다 앞섬 | 특별한 조치 불필요 |
| **또래 수준** | 정상 범위 | 유지 |
| **추적검사 요망** | 경계선 | **1~2개월 뒤 재검사** 또는 자극 활동 후 재평가 |
| **심화평가 권고** | 지연 의심 | **소아청소년과·재활의학과·소아정신과 정밀 평가 의뢰** |

### 중요한 주의
- **부모가 솔직하게 답해야 의미가 있습니다.** 잘 보이려고 실제보다 높게 체크하면 조기 발견 기회를 잃습니다. **"가끔 한다"와 "잘 한다"를 구분**해서 체크하세요.
- **선별검사는 진단이 아닙니다.** "심화평가 권고"가 곧 장애를 의미하지 않습니다.
- 반대로 **"또래 수준"이 나와도 부모가 걱정된다면 말하세요.** 부모의 우려는 유의미한 임상 정보입니다.
- **미숙아는 교정연령**(예정일 기준)으로 평가합니다. 보통 만 2세까지 교정연령을 적용합니다.

## 3. 자폐 스펙트럼 선별 — M-CHAT-R/F

- **대상: 생후 16~30개월.** AAP는 **18개월과 24개월에 모든 아동**에게 시행할 것을 권고합니다. **[강함]**
- 20문항의 부모 작성 설문이며, 위험도가 나오면 후속 면담(Follow-up)으로 확인합니다.
- 한국어판이 있으며, 소아과에서 요청하면 시행하는 경우가 많습니다. **먼저 물어보세요.** 국내에서 일상적으로 시행되지 않는 경우도 있습니다.
- **왜 중요한가**: 자폐 스펙트럼은 조기 개입 시 결과가 크게 달라집니다. 평균 진단 연령은 여전히 늦고, 조기 발견이 가장 큰 개선 여지입니다.

### 관련 조기 신호 (12~24개월)
- 이름을 불러도 반복적으로 반응 없음
- **가리키기 없음 / 시선을 따라가지 않음**
- 관심을 공유하려는 몸짓이 없음 (물건을 보여주려 가져오지 않음)
- 눈맞춤이 드묾
- 흉내내기 놀이가 없음
- **획득한 말이나 사회성의 퇴행** — 어떤 시기든 즉시 평가 대상

## 4. 예방접종 표준일정 (국가예방접종, 무료)

> 아래는 개요이며, **반드시 예방접종도우미(nip.kdca.go.kr)에서 최신 표준일정표를 확인**하세요. 백신 종류(콤보 백신), 접종 횟수, 대상 연령은 변경될 수 있습니다.

| 백신 | 예방 질병 | 접종 시기 |
|------|-----------|-----------|
| **BCG** | 결핵 | **생후 4주 이내 1회** |
| **HepB** | B형간염 | 0, 1, 6개월 (3회) |
| **DTaP** | 디프테리아·파상풍·백일해 | 2, 4, 6개월 · 15~18개월 · 만 4~6세 (5회) |
| **IPV** | 폴리오 | 2, 4, 6~18개월 · 만 4~6세 (4회) |
| **Hib** | b형 헤모필루스 인플루엔자 | 2, 4, 6개월 · 12~15개월 (4회) |
| **PCV** | 폐렴구균 | 2, 4, 6개월 · 12~15개월 (4회) |
| **RV** | 로타바이러스 | RV1: 2, 4개월 / RV5: 2, 4, 6개월 — **생후 8개월 이전 완료** |
| **MMR** | 홍역·유행성이하선염·풍진 | 12~15개월 · 만 4~6세 (2회) |
| **VAR** | 수두 | 12~15개월 1회 |
| **HepA** | A형간염 | 12~23개월 1차, 6개월 이상 간격 후 2차 |
| **JE** | 일본뇌염 | 불활성화: 12~23개월부터 총 5회 / 약독화 생백신: 12~23개월부터 2회 |
| **IIV** | 인플루엔자 | **생후 6개월부터 매년**. 첫 접종 연도는 4주 간격 2회 |
| **HPV** | 사람유두종바이러스 | 만 12세 전후 (대상·성별 정책 확인 필요) |

### 접종 실무 팁
- **접종 후 30분은 병원 내 또는 근처에 머무릅니다** (즉시형 이상반응 관찰).
- 접종 부위 발적·미열은 흔합니다. **38.5℃ 이상 지속되거나 축 처지면 병원**.
- **예방접종 전 미리 해열제를 먹이지 않습니다** — 항체 형성을 낮출 수 있다는 보고가 있습니다.
- 감기 정도의 가벼운 질환은 대부분 접종 가능합니다. 판단은 의사에게.
- 일정이 밀렸다면 **처음부터 다시 하지 않습니다.** 이어서 하면 됩니다.
- 접종 기록은 **예방접종도우미에 자동 기록**되며, 어린이집·유치원 제출 서류를 여기서 출력할 수 있습니다.

### 유료(선택) 접종 검토 대상
로타바이러스 외에도 시기·정책에 따라 유료인 백신이 있을 수 있습니다. **수막구균, RSV 예방 항체(니르세비맙 등), 코로나19** 등은 정책과 권고가 자주 바뀌므로 소아과와 상의하세요.

## 5. 신생아 시기 별도 검사 (출산 병원에서 시행)

| 검사 | 시기 | 놓치면 안 되는 이유 |
|------|------|---------------------|
| **선천성 대사이상 검사** | 생후 48시간~7일 | 조기 치료로 지적장애 등 예방 가능 |
| **신생아 난청 선별검사** | 퇴원 전 | 조기 발견 시 언어 발달 결과가 크게 달라짐. **재검 안내를 받으면 반드시 3개월 이내 확진 검사** |
| 선천성 심장질환 산소포화도 검사 | 퇴원 전 | 병원에 따라 시행 |
| 발달성 고관절 이형성증 확인 | 신생아~영아 검진 | 초음파/진찰. 조기 발견 시 간단한 치료로 해결 |

**결과지를 반드시 받아 보관하고, 재검 안내는 미루지 마세요.**

## 6. 시력·청력 — 놓치기 쉬운 두 가지

### 시력
- **약시(amblyopia)는 만 7~8세 이전에 치료해야 회복 가능성이 높습니다.** 이후엔 교정이 어렵습니다.
- **만 3~5세에 반드시 시력 검사**를 받으세요(건강검진 6·7차에 포함).
- 가정 관찰 신호: 한쪽 눈을 자주 감거나 가림 / 고개를 기울여 봄 / 눈이 몰림(사시) / TV에 지나치게 가까이 감 / 눈을 자주 비빔
- **생후 4개월 이후에도 눈이 지속적으로 몰리면** 즉시 안과 진료.

### 청력
- 신생아 선별검사를 통과했어도 **후천적 난청**이 생길 수 있습니다.
- 관찰 신호: 큰 소리에 놀라지 않음 / 이름에 반응 없음 / **6개월 이후 옹알이가 줄거나 사라짐** / 말이 늦음
- 중이염이 잦으면 청력·언어에 영향을 줄 수 있으므로 추적이 필요합니다.

## 7. 성장 곡선 읽는 법

- **0~24개월은 WHO 성장기준**, 이후는 2017 소아청소년 성장도표를 사용합니다.
- 한 시점의 백분위수보다 **곡선의 추세**가 중요합니다.
  - 3백분위수여도 **자기 곡선을 따라 꾸준히 크면 대개 정상**입니다.
  - 반대로 50백분위에서 15백분위로 **두 개 이상의 주요 백분위선을 가로질러 떨어지면** 평가가 필요합니다.
- 생후 첫 며칠 체중 감소(출생 체중의 최대 7~10%)는 정상이며, **약 2주 내 회복**되어야 합니다.
- 머리둘레는 **뇌 성장의 지표**입니다. 급격한 증가나 정체는 반드시 확인합니다.

## 8. 발달 지연이 의심될 때 — 한국에서의 경로

```
1단계   가정에서 관찰 · K-DST 문진표 · [11-red-flags.md] 확인
              ↓
2단계   소아청소년과 방문 (걱정되는 점을 구체적으로 기록해서 가기)
              ↓
3단계   심화평가 의뢰 — 소아재활의학과 / 소아정신건강의학과 / 발달센터
        (베일리 영유아 발달검사, 언어평가, ADOS-2 등)
              ↓
4단계   진단 및 치료 시작 — 언어치료 / 작업치료 / 물리치료 / 행동치료(ABA)
              ↓
5단계   지원 신청
        · 영유아 발달정밀검사비 지원 (보건소 / 건강보험공단 — 소득 기준 확인)
        · 발달재활서비스 바우처 (만 18세 미만, 소득 기준)
        · 장애아동수당 · 장애인 등록 (해당 시)
        · 지역 육아종합지원센터 · 발달장애인지원센터
```

### 핵심 원칙
> **"기다려 봅시다"를 그냥 받아들이지 마세요.**
> 조기 개입의 효과는 시기에 크게 좌우됩니다. 걱정된다면 재평가 시점을 **명시적으로 정하고**(예: "2개월 뒤 다시 보자") 나오세요. 그래도 불안하면 **2차 소견**을 받는 것이 합리적입니다. 개입해서 손해 보는 경우는 거의 없습니다.

## 9. 병원 갈 때 준비 체크리스트

- [ ] 걱정되는 점을 **구체적인 사례로** 적어 가기 ("말이 늦어요" ❌ → "24개월인데 쓰는 단어가 10개 정도이고 두 단어를 붙이지 않아요" ✅)
- [ ] **영상 촬영** — 걷는 모습, 노는 모습, 걱정되는 행동. 병원에서는 안 하는 경우가 많습니다
- [ ] 아기수첩 / 접종 기록 / 이전 검진 결과
- [ ] 질문 3개를 미리 적기 (진료실에서는 잊어버립니다)
- [ ] 물어볼 것: **"다음에 무엇을 보면 다시 와야 하나요?"** — 이 질문 하나가 가장 유용합니다
