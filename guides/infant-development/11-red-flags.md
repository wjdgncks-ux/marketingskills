# 11. 경고 신호 (Red Flags) — 언제 병원에 가야 하는가

인터넷 검색 대신 이 문서를 보세요. **모든 항목은 "즉시 병원에 가라"가 아니라 "전문가에게 물어보라"는 뜻**입니다. 확인해서 아무 일 아니면 그걸로 좋은 겁니다.

> 발달 이정표는 CDC 2022 개정판 기준이며, **해당 월령 아이의 약 75%가 할 수 있는 것**입니다. 못 한다고 반드시 문제인 것은 아니지만, **상담을 시작하라는 신호**로 설계되었습니다.

---

## 1. 🚨 어느 시기든, 즉시 응급실

| 증상 | 왜 |
|------|-----|
| **생후 3개월 미만 + 체온 38.0℃ 이상** | 신생아 중증 감염 가능성. **해열제로 지켜보지 말 것** |
| 호흡 곤란 — 갈비뼈 사이 함몰, 코 벌렁임, 신음, 입술·얼굴 청색증 | 호흡부전 |
| **경련(발작)** | 5분 이상 지속되면 즉시 119 |
| 축 늘어지고 깨워도 반응이 약함 | 중증 감염·대사 이상·탈수 |
| 목이 뻣뻣하거나 빛을 심하게 싫어함 + 발열 | 수막염 의심 |
| **누르면 사라지지 않는 붉은/보라색 반점** (유리컵으로 눌러 확인) | 수막알균 감염 의심 |
| 심한 탈수 — 8~12시간 소변 없음, 눈물 없이 욺, 입안이 마름, 처짐 | 탈수 |
| **버튼형 전지·자석 구슬을 삼킨 것으로 의심** | 몇 시간 내 식도 천공/장 천공 가능. **즉시** |
| 심한 두부 외상 후 구토·의식 저하·한쪽 팔다리 힘 빠짐 | 두개내 출혈 |
| 담즙성(초록색) 구토, 혈변, 젤리 같은 점액혈변 | 장중첩증·장폐색 |
| 화상, 삼킨 세제·약물 | 즉시 |

**미리 준비**: 소아 응급실 있는 병원 2곳의 위치·번호를 냉장고에 붙여두기. 야간 상담 **1339**.

## 2. 시기별 발달 경고 신호

### 생후 2개월
- [ ] 큰 소리에 반응이 없다
- [ ] 움직이는 물체를 눈으로 따라가지 않는다
- [ ] **사람을 보고 미소 짓지 않는다**
- [ ] 손을 입으로 가져가지 않는다
- [ ] 엎드렸을 때 머리를 전혀 들지 못한다

### 생후 4개월
- [ ] **머리를 가누지 못한다**
- [ ] 소리를 내지 않는다(옹알이 없음)
- [ ] 물건을 입으로 가져가지 않는다
- [ ] 사람을 보고 웃지 않는다
- [ ] 다리에 힘을 주고 딛으려 하지 않는다
- [ ] 한쪽 팔·다리만 주로 쓴다 (좌우 비대칭)

### 생후 6개월
- [ ] **양쪽 어느 방향으로도 뒤집지 못한다**
- [ ] 웃거나 기쁨을 표현하지 않는다
- [ ] 소리에 반응해 소리를 내지 않는다
- [ ] 자음이 섞인 옹알이("바바", "다다")가 없다
- [ ] 물건에 손을 뻗지 않는다
- [ ] 몸이 축 늘어지거나 반대로 지나치게 뻣뻣하다

### 생후 9개월
- [ ] **도움 없이 앉지 못한다**
- [ ] **자기 이름에 반응하지 않는다**
- [ ] 아는 사람을 알아보지 못한다
- [ ] 옹알이가 없거나 줄었다
- [ ] 눈을 마주치지 않는다
- [ ] 몸무게를 다리로 지탱하지 못한다

### 생후 12개월 — 특히 중요
- [ ] **아무것도 가리키지 않는다** ← 가장 중요한 신호
- [ ] 손 흔들기·짝짜꿍 등 **몸짓이 없다**
- [ ] 잡고 서지 못한다
- [ ] 기지 못한다 (또는 한쪽으로만 기어간다)
- [ ] 의미 있는 말소리가 전혀 없다
- [ ] 숨긴 물건을 찾지 않는다
- [ ] **이전에 하던 것을 못 하게 되었다(퇴행)**

### 생후 18개월
- [ ] **의미 있는 낱말이 없다**
- [ ] 다른 사람의 행동을 흉내내지 않는다
- [ ] **재미있는 것을 보여주려고 가져오지 않는다**
- [ ] 혼자 걷지 못한다
- [ ] 자기 손을 어떻게 쓰는지 모르는 듯하다
- [ ] 눈맞춤을 피한다

### 생후 24개월
- [ ] **두 낱말을 붙여 말하지 못한다**
- [ ] 사용하는 낱말이 **50개 미만**
- [ ] 간단한 지시를 따르지 못한다
- [ ] 흉내내기·상상놀이를 하지 않는다
- [ ] 안정적으로 걷지 못하거나 자주 넘어진다
- [ ] **획득했던 말·기술을 잃었다(퇴행)**
- [ ] 물건을 용도에 맞게 쓰지 못한다(숟가락, 컵, 빗)

### 만 3세
- [ ] 말이 **낯선 사람에게 거의 전달되지 않는다**(명료도 75% 미만)
- [ ] 문장으로 말하지 않는다
- [ ] 다른 아이에게 관심이 없다
- [ ] 간단한 지시를 이해하지 못한다
- [ ] 상상놀이를 하지 않는다
- [ ] 눈을 마주치지 않는다
- [ ] 심하게 자주 넘어지거나 계단을 못 오른다
- [ ] 부모와 떨어질 때 전혀 진정되지 않는다

### 만 4~5세
- [ ] 짧은 문장으로만 말한다
- [ ] 또래와 놀지 못하고 계속 혼자 있다
- [ ] 규칙 있는 놀이를 이해하지 못한다
- [ ] 자기 이름·나이를 모른다
- [ ] 배변 조절이 낮에도 전혀 안 된다
- [ ] 극도로 위축되거나 반대로 공격적이다
- [ ] 집중 시간이 또래에 비해 현저히 짧다

## 3. 어떤 나이든 즉시 평가해야 하는 3가지

### ① 퇴행(Regression)
**하던 것을 못 하게 되는 것**은 어느 시기, 어떤 영역이든 **즉시 평가 대상**입니다.
- 말하던 단어가 사라짐
- 눈맞춤·사회적 반응이 줄어듦
- 걷던 아이가 걷지 못함
- 대소변을 가리던 아이가 완전히 퇴행하고 지속됨 (스트레스성 일시적 퇴행과 구분 필요)

### ② 좌우 비대칭
- 한쪽 손만 쓴다 — **만 18개월 이전의 뚜렷한 손잡이 선호는 비정상 신호**일 수 있습니다(뇌성마비 등). 손잡이는 보통 2~4세에 확립됩니다.
- 한쪽 팔·다리만 움직임이 적다
- 얼굴이 한쪽만 움직인다

### ③ 근긴장 이상
- 지나치게 축 늘어짐(저긴장) — 안으면 미끄러지듯 흘러내림
- 지나치게 뻣뻣함(고긴장) — 다리가 가위처럼 교차, 주먹을 계속 꽉 쥠(생후 3~4개월 이후에도)

## 4. 신체 증상 — 병원에 가는 기준

### 발열
| 나이 | 기준 |
|------|------|
| **3개월 미만** | **38.0℃ 이상 → 즉시 응급실** (해열제 금지, 관찰 금지) |
| 3~6개월 | 38.5℃ 이상 또는 처짐 → 당일 진료 |
| 6개월 이상 | 열 자체보다 **아이의 상태**가 기준. 열이 내렸을 때 잘 놀면 대개 안심 |
| 모든 나이 | 5일 이상 지속되는 발열 → 진료 (가와사키병 등 감별) |

**해열제**: 아세트아미노펜(생후 2~3개월 이후, 체중 기준), 이부프로펜(**생후 6개월 이후**). 반드시 **체중 기준 용량**으로. 아스피린은 절대 금지(라이 증후군).

### 구토·설사
- 탈수 신호가 우선입니다: 소변량 감소, 눈물 없이 욺, 입안 건조, 처짐, 대천문 함몰
- **초록색(담즙성) 구토, 혈변, 젤리 같은 점액혈변 → 즉시**
- 분수처럼 뿜는 구토가 반복되면(특히 생후 2~8주) → 유문협착증 감별

### 호흡
- 숨 쉴 때 갈비뼈 사이·목 아래가 쑥 들어감(함몰호흡)
- 숨소리가 쌕쌕거리거나 컹컹 짖는 기침(크루프)
- 호흡수가 비정상적으로 빠름 (영아 60회/분 이상)
- 입술·손톱이 파래짐 → **즉시**

### 피부·황달
- 생후 첫 주 이후에도 황달이 심해지거나 **팔다리까지 노랗게** → 즉시
- **생후 2주 이후에도 지속되는 황달** → 담도폐쇄증 등 감별 필요 (대변 색이 옅은 회백색이면 특히)
- 누르면 사라지지 않는 자반 → 즉시

## 5. 부모의 직관을 무시하지 마세요

연구와 임상 경험 모두, **"뭔가 이상하다"는 부모의 느낌은 유의미한 임상 신호**입니다. 부모는 아이를 가장 많이 관찰한 사람입니다.

- 진료실에서 "괜찮다"는 말을 들었는데도 계속 걱정된다면 → **구체적 근거를 적고 재방문하거나 2차 소견**을 받으세요.
- "지켜보자"는 말을 들었다면 → **"언제까지, 무엇을 보면 다시 와야 하나요?"**를 반드시 물으세요.
- 발달 문제에서 **기다려서 얻는 이익은 거의 없고, 조기 개입에서 얻는 이익은 큽니다.**

## 6. 반대로, 걱정하지 않아도 되는 것들

불필요한 불안을 줄이는 것도 중요합니다.

| 흔한 걱정 | 실제 |
|-----------|------|
| 배밀이를 건너뛰고 바로 걸음 | 기기를 건너뛰는 아이는 흔하며, 대개 문제 없습니다 |
| 12~15개월에 아직 안 걸음 | **18개월까지 걷지 않으면** 평가 대상. 그 전엔 정상 범위가 넓습니다 |
| 까치발로 걷는다 | 간헐적이면 흔합니다. **항상 까치발이고 종아리가 뻣뻣하면** 평가 |
| 밤에 자주 깬다 | 돌 전후까지 흔합니다 |
| 이가 늦게 난다 | 첫니는 3~13개월까지 범위가 넓습니다. **18개월까지 하나도 없으면** 확인 |
| 대천문이 늦게 닫힘 | 보통 9~18개월. 24개월까지도 정상 범위 |
| 편식이 심하다 | 2~5세엔 정상. **성장 곡선이 유지되면** 대개 괜찮습니다 |
| 말이 조금 느리다 | 개인차가 큽니다. 단, **위의 이정표 기준**은 확인하세요 |
| 안짱다리·O다리 | 2세 전 O다리, 3~4세 X다리는 흔한 정상 변화입니다 |
| 자꾸 넘어진다 (걸음마 초기) | 정상. **점점 나빠지면** 평가 |
