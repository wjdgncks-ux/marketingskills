# 12. 안전 — 실제로 생명을 지키는 항목들

육아에서 통계적으로 아이의 생명에 가장 큰 영향을 주는 것은 교육법이 아니라 **안전한 수면, 카시트, 익수 예방, 삼킴 사고 예방**입니다. 이 문서의 항목들은 **선택이 아니라 기본값**으로 다루세요.

---

## 1. 안전한 수면 (SIDS/질식사 예방) — 만 1세까지

AAP의 2022년 안전 수면 권고 기준입니다. **[강함]**

### 반드시 지킬 것 (ABC)
```
Alone  — 혼자    (같은 방, 다른 잠자리)
Back   — 등을 대고
Crib   — 단단하고 평평한 잠자리에서
```

| 항목 | 내용 |
|------|------|
| **자세** | **항상 등을 대고.** 낮잠 포함, 만 1세까지. 스스로 뒤집을 수 있게 되면 그때는 되돌리지 않아도 됩니다(눕힐 때만 등으로) |
| **바닥** | 단단하고 **평평한** 매트리스 + 딱 맞는 시트 1장. 경사(인클라인) 제품 금지 |
| **잠자리 안** | 베개·이불·범퍼·인형·수면쿠션·포지셔너 **전부 금지** |
| **방** | **같은 방, 다른 잠자리** — 최소 6개월, 가능하면 12개월 |
| **온도** | 서늘하게. 이불 대신 **수면조끼**. 과열은 위험 요인 |
| **금연** | 임신 중·출생 후 흡연 노출은 주요 위험 요인 |
| **모유수유** | 위험을 낮추는 것으로 보고됨 |
| **쪽쪽이** | 모유수유 확립 후(대략 3~4주) 낮잠·밤잠 시 사용은 위험을 낮춤 |
| **예방접종** | 일정대로 접종한 영아에서 위험이 낮게 보고됨 |

### 절대 하면 안 되는 것
- **소파·안락의자에서 아기와 함께 잠들기** — 침대에서의 동침보다도 위험이 높습니다
- 카시트·유모차·아기띠·바운서에서 **재우기** (이동 중 잠든 경우, 도착하면 평평한 곳으로 옮깁니다)
- 부모가 음주·약물·극심한 피로 상태에서 아이와 같은 잠자리 사용
- 뒤집기 시작한 뒤의 **속싸개(스와들)** 사용
- SIDS 예방을 표방하는 상업적 모니터·기기를 **안전 대책으로 신뢰**하는 것 (의학적 근거 없음)

### 침구·의류
- 수면조끼(sleep sack)의 **TOG 지수**로 실내 온도에 맞춥니다. 손발이 약간 시원한 것은 정상이며, **목덜미·가슴이 땀에 젖어 있으면 과열**입니다.
- 모자를 씌우고 재우지 않습니다(체온 방출 방해).

---

## 2. 카시트 — 차에 탈 때마다, 예외 없이

### 원칙
1. **뒤보기(후방보기)를 최대한 오래.** 최소 만 2세, 가능하면 카시트가 허용하는 신장·체중 한계까지. 뒤보기는 충돌 시 목과 척추 손상을 크게 줄입니다. **[강함]**
2. **뒷좌석.** 조수석 에어백은 아이에게 치명적일 수 있습니다.
3. **하네스 조임**: 어깨끈을 잡아당겼을 때 **손가락으로 접히는 여유가 없을 정도**. 가슴 클립은 **겨드랑이 높이**.
4. **두꺼운 외투는 벗기고** 태웁니다. 패딩이 압축되면 하네스에 큰 여유가 생겨 충돌 시 튕겨 나갈 수 있습니다. 태운 뒤 담요를 덮어주세요.
5. 대한민국 도로교통법상 **만 6세 미만은 카시트 착용 의무**입니다. 실제 안전을 위해서는 **신장 약 150cm까지 부스터** 사용이 권고됩니다.

### 흔한 실수
- 설치 각도 부정확 (신생아는 기울기 각도 표시 확인 — 고개가 앞으로 꺾이면 기도 폐쇄 위험)
- 벨트/ISOFIX 고정이 느슨함 — **벨트 경로에서 좌우로 2.5cm 이상 움직이면** 다시 설치
- 중고·사고 이력 카시트 사용
- 카시트에서 오래 자게 두기 (신생아는 각도상 호흡 곤란 위험 — **차에서 내리면 평평한 곳으로**)

### 절대 금지
- **아이를 차 안에 혼자 두기.** 짧은 시간이라도 안 됩니다. 차내 온도는 매우 빠르게 치명적 수준까지 오릅니다.

---

## 3. 익수(물) — 조용하고 빠릅니다

- **영유아는 2~3cm 깊이의 물에서도 익사할 수 있습니다.** 욕조, 세숫대야, 변기, 양동이, 정원의 물통.
- **익사는 소리 없이 일어납니다.** 첨벙거리며 소리치는 장면은 영화입니다.
- 규칙
  - 목욕 중에는 **절대 자리를 뜨지 않습니다.** 전화·초인종이 울려도 **아이를 안고** 이동합니다.
  - 목욕 후 **즉시 물을 뺍니다.**
  - 변기 뚜껑 잠금장치, 욕실 문 닫아두기
  - 물놀이 시 **팔에 끼는 튜브는 안전장비가 아닙니다.** 구명조끼를 쓰고, 어른이 팔 뻗으면 닿는 거리에서 지켜봅니다("touch supervision")
  - 만 1세 이후 수영 강습은 익수 위험을 낮추는 데 도움이 될 수 있으나, **감독을 대체하지 않습니다**

---

## 4. 삼킴·질식

### 질식 위험 음식 (만 4세까지)
통 견과류 · 통 포도 · 방울토마토 · 팝콘 · 사탕·젤리 · 동그랗게 썬 소시지 · 딱딱한 생당근 · 껌 · 마시멜로 · 떡

**대응**: 포도·방울토마토는 **세로로 4등분**, 소시지는 세로로 갈라서, 견과류는 갈아서. **먹을 때는 앉아서, 걸어 다니며 먹지 않기.**

### 삼키면 즉시 응급실
- **버튼형 리튬 전지** — 식도에 걸리면 **2시간 내에도 화학 화상·천공**이 생깁니다. 리모컨, 자동차 키, 체중계, 전자 촛불, 노래하는 카드, 체온계 확인
- **자석 구슬 2개 이상** — 장을 사이에 두고 붙어 천공
- 동전, 바늘, 뾰족한 물건
- 약물, 세제(특히 캡슐형 세제 — 색이 예뻐서 아이가 삼킵니다)

### 크기 기준
> **화장지 심(지름 약 3.2cm)을 통과하는 물건은 삼킬 수 있습니다.** 이 기준으로 집을 점검하세요.

### 기타 질식·교살 위험
- 블라인드·커튼 **줄** — 줄 없는 제품으로 교체 권장
- 비닐봉지, 풍선(터진 조각이 가장 위험)
- 목에 거는 것 일체 — 이앓이 목걸이, 쪽쪽이 줄(잠자리에서 금지)
- 침대와 벽 사이 틈

## 5. 집안 안전 — 기기 시작 전에 완료

### 월령별 타이밍
| 시기 | 해야 할 것 |
|------|-----------|
| 출생 전 | 카시트, 안전한 잠자리 |
| 4~6개월 | 가구 벽 고정, 작은 물건 정리 (뒤집기 시작 전) |
| **6~9개월** | **전면 안전 점검 완료** (기기 시작 전) |
| 9~12개월 | 계단 안전문, 서랍 잠금 (서기·크루징 시작) |
| 12~24개월 | 창문·베란다, 높은 곳 오르기 대비 |

### 체크리스트
- [ ] **가구·TV 벽 고정** — 넘어짐 사고는 치명적입니다. 서랍장, 책장, TV 전부
- [ ] 콘센트 안전커버
- [ ] 계단 위·아래 안전문 — **위쪽은 반드시 벽에 나사로 고정하는 방식**
- [ ] 서랍·수납장 잠금 — 세제, 약, 칼, 비닐
- [ ] 모서리 보호대 (테이블, 선반)
- [ ] 블라인드 줄 제거·정리
- [ ] 식탁보 치우기
- [ ] 뜨거운 것: 정수기 온수 잠금, 전기포트·밥솥 위치, **냄비 손잡이는 안쪽으로**
- [ ] **창문 잠금 / 방충망은 추락을 막지 못합니다.** 창가에 올라갈 수 있는 가구를 두지 않기
- [ ] 베란다 문 잠금
- [ ] 화장실 문 닫기, 변기 잠금
- [ ] 반려동물과 아이 단둘이 두지 않기
- [ ] **화재경보기 설치 및 배터리 점검**
- [ ] 약·비타민은 **높고 잠긴 곳에** (어린이 보호 뚜껑도 완전하지 않습니다)
- [ ] 담배·전자담배 액상 — 니코틴은 소량으로도 치명적

### 화상 예방
- 목욕물 온도 **37~38℃**, 팔꿈치나 온도계로 확인. 온수기 최고 온도를 낮춰 설정
- 아이를 안고 뜨거운 음료를 들지 않기
- 전자레인지로 데운 분유·이유식은 **반드시 저어서 온도 확인** (부분적으로 매우 뜨거울 수 있음)

## 6. 야외·이동

- **유모차·유아용 의자·쇼핑카트: 항상 안전벨트.** 낙상 사고의 대부분이 벨트 미착용입니다
- **아기띠**: 고관절에 안전한 M자 자세(무릎이 엉덩이보다 높게). 신생아는 **기도 확보** — 턱이 가슴에 붙지 않도록, 얼굴이 항상 보이도록
- **보행기 사용 금지** (AAP 권고). 대신 밀기 장난감
- 자전거·킥보드·인라인: **안전모 필수**, 처음부터 습관화
- 주차장·차 주변: 후진 사고. 차 뒤에 아이가 없는지 항상 확인

## 7. 응급 대비 — 미리 해둘 것

### ① 영유아 심폐소생술(CPR)과 기도폐쇄 응급처치를 배우기
**부모라면 반드시 배워야 합니다.** 영아와 소아의 방법은 성인과 다릅니다.
- 대한적십자사, 소방서, 보건소에서 무료·저가 교육을 운영합니다
- 배우자와 함께, 그리고 아이를 돌볼 조부모·도우미도 함께 받으세요

### 기도폐쇄 시 (기억용 요약 — 반드시 실습 교육으로 익힐 것)
- **1세 미만**: 머리를 낮게 하여 등 두드리기 5회 → 가슴 압박 5회, 반복
- **1세 이상**: 복부 밀어내기(하임리히)
- **소리를 내거나 기침을 할 수 있으면 개입하지 말고 기침을 유도**합니다. 아무 소리도 못 낼 때가 완전 폐쇄입니다
- 의식을 잃으면 **즉시 119 + CPR**

### ② 냉장고에 붙여둘 정보
```
119 (응급)
1339 (응급의료 상담)
소아 응급실 병원 ①: ____________  ☎ ________
소아 응급실 병원 ②: ____________  ☎ ________
다니는 소아과:      ____________  ☎ ________
아이 생년월일 / 체중 / 알레르기 / 복용약:
집 주소 (구급대에게 불러줄 정확한 주소):
```

### ③ 가정 구급함
- 체온계(직장·구강 겸용 1개 필수 — 3개월 미만은 직장 체온이 기준)
- 아세트아미노펜 시럽 / (6개월 이후) 이부프로펜 시럽 — **체중별 용량을 미리 의사에게 확인해 적어두기**
- 생리식염수, 코 흡입기
- 밴드, 소독약, 거즈, 화상 거즈
- 경구수액제(ORS)
- 손톱가위, 핀셋

---

## 8. 온라인 안전 (부모의 행동)

- **셰어런팅(sharenting)**: 아이 사진·이름·생일·어린이집 위치를 공개 계정에 올리는 것은 장기적 프라이버시 위험을 만듭니다. 아이는 동의할 수 없습니다
- 목욕·기저귀 사진은 올리지 않기
- 계정 공개 범위와 위치정보(EXIF) 확인
