# 17. 실행 트래커 — 기록하고 확인하는 도구

읽는 것만으로는 실행되지 않습니다. 이 문서의 템플릿을 복사해서 쓰세요. **한 달에 5분**이면 충분합니다.

---

## 1. 전체 일정 마스터 캘린더

출산 전에 **달력 앱에 미리 전부 등록**해두세요. 이것 하나만 해도 놓치는 일이 크게 줄어듭니다.

| 시점 | 일정 | 등록 |
|------|------|------|
| 출생 후 4주 이내 | **BCG 접종** | ☐ |
| 출생 후 1개월 이내 | **출생신고** + 행복출산 원스톱 | ☐ |
| **생후 14~35일** | **영유아 건강검진 1차** | ☐ |
| 생후 1개월 | B형간염 2차 | ☐ |
| 생후 2개월 | DTaP·IPV·Hib·PCV·로타 1차 | ☐ |
| 생후 4개월 | 2차 접종 세트 | ☐ |
| **생후 4~6개월** | **영유아 건강검진 2차** (K-DST 시작) | ☐ |
| 생후 6개월 | 3차 접종 세트 + B형간염 3차 | ☐ |
| 생후 6개월~ | **인플루엔자 (매년 가을)** | ☐ |
| **생후 9~12개월** | **영유아 건강검진 3차** | ☐ |
| 생후 12~15개월 | MMR·수두·A형간염·일본뇌염·Hib·PCV 추가 | ☐ |
| **생후 18개월** | **자폐 선별(M-CHAT) 요청** | ☐ |
| 생후 15~18개월 | DTaP 4차 | ☐ |
| **생후 18~24개월** | **영유아 건강검진 4차** | ☐ |
| **생후 18~29개월** | **구강검진 1차** | ☐ |
| **생후 24개월** | **자폐 선별(M-CHAT) 재확인** | ☐ |
| **생후 30~36개월** | **영유아 건강검진 5차** | ☐ |
| **생후 30~41개월** | **구강검진 2차** | ☐ |
| **생후 42~48개월** | **영유아 건강검진 6차** (+시력) | ☐ |
| **생후 42~53개월** | **구강검진 3차** | ☐ |
| 만 4~6세 | DTaP 5차·IPV 4차·MMR 2차 (**취학 전 접종**) | ☐ |
| **생후 54~60개월** | **영유아 건강검진 7차** | ☐ |
| **생후 54~65개월** | **구강검진 4차** | ☐ |
| **생후 66~71개월** | **영유아 건강검진 8차** | ☐ |
| 첫니 후 6개월 이내 | **첫 치과 방문**, 이후 6개월마다 | ☐ |

> 정확한 접종 일정은 **예방접종도우미(nip.kdca.go.kr)에 자녀를 등록**하면 자동으로 관리됩니다. 가장 확실한 방법입니다.

## 2. 월간 점검표 (매달 5분)

복사해서 매달 채우세요.

```
─────────────────────────────────────────
📅 월령: ______개월        날짜: __________

■ 발달 이정표 (해당 월령 문서 확인)
  □ 대근육   가능 / 부분 / 아직    메모:
  □ 소근육   가능 / 부분 / 아직    메모:
  □ 언어     가능 / 부분 / 아직    메모:
  □ 인지     가능 / 부분 / 아직    메모:
  □ 사회정서 가능 / 부분 / 아직    메모:

■ 경고 신호 ([11-red-flags.md] 해당 월령 확인)
  □ 해당 없음
  □ 있음 → 무엇:
     → 조치:  □ 관찰   □ 소아과 예약(날짜:      )

■ 이번 달 새로 생긴 것 (기록해두면 나중에 큰 자산)
  첫 ______________  날짜: ______

■ 부모 자신
  수면: 하루 평균 ___시간
  기분(1~5):  나 ___   배우자 ___
  □ 2주 이상 우울·불안이 지속되고 있다 → 상담 예약

■ 일상 습관 점검
  □ 매일 책 읽기를 하고 있다
  □ 하루 실외 활동을 하고 있다
  □ 화면 노출이 기준 안에 있다
  □ 안전 점검이 현재 월령에 맞게 되어 있다

■ 다음 달 할 일
  □ 예방접종:
  □ 검진:
  □ 준비물:
─────────────────────────────────────────
```

## 3. 병원 방문 준비 시트

진료 시간은 짧습니다. **미리 적어 가면 완전히 달라집니다.**

```
─────────────────────────────────────────
방문일: ________   월령: ____개월   체중: ____kg

■ 오늘 물어볼 것 (3개까지)
  1.
  2.
  3.

■ 걱정되는 것 — 구체적으로
  언제부터:
  얼마나 자주:
  어떤 상황에서:
  (영상 촬영해 왔는가?  □ 예  □ 아니오)

■ 현재 상태
  수유/식사:
  수면:
  배변:
  복용 중인 약:

■ 반드시 물을 질문
  "다음에 무엇을 보면 다시 와야 하나요?"
  "언제 다시 확인해야 하나요?"

■ 의사 답변 메모
─────────────────────────────────────────
```

## 4. 시기별 준비물 구매 트리거

**미리 사지 말고, 아래 신호가 보이면 그때 사세요.**

| 신호 | 그때 살 것 |
|------|-----------|
| 목을 가누기 시작 | (아직 없음) |
| **뒤집기 조짐** | 속싸개 중단 → 수면조끼 · **가구 벽 고정 시작** |
| **혼자 앉기 시작** | 이유식 의자, 이유식 도구 |
| **첫니가 남** | 아기 칫솔 + 불소 치약 |
| **배밀이/기기 시작** | **안전용품 전면 설치** (콘센트·서랍·안전문) |
| **잡고 서기 시작** | 계단 안전문, 낮은 가구 재배치 |
| **걷기 시작** | 실외용 신발, 밀기 장난감 |
| 아기침대 난간을 넘으려 함 | 유아 침대 전환 |
| **배변 준비 신호** | 유아 변기, 팬티 |
| 자전거·킥보드 관심 | **안전모** (동시에 구매) |
