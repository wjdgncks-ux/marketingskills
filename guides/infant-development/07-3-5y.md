# 07. 만 3~5세 — 또래, 실행기능, 학교 준비

이 시기 아이는 **사회적 존재**가 됩니다. 친구가 생기고, 규칙을 배우고, 상상의 세계가 폭발합니다. 부모의 관심은 자연스럽게 "학교 준비"로 향하지만, **초등학교 성취를 가장 잘 예측하는 것은 한글·연산이 아니라 자기조절과 언어 능력**입니다.

**한 줄 요약: 글자를 가르치는 것보다, 자기 감정과 주의를 조절하는 힘을 길러주는 것이 학교 준비입니다.**

---

## 1. 발달 이정표 (CDC 2022 · 약 75% 기준)

### 만 4세
| 영역 | 이정표 |
|------|--------|
| 사회·정서 | **다른 아이를 위로하거나 도우려 한다** · "나 좀 봐" 하며 자랑한다 · 부모가 없어도 논다 |
| 언어 | **4단어 이상 문장** · 최소 4개의 색을 안다 · 방금 있었던 일을 말한다 · 노래·시를 외운다 |
| 인지 | 무엇/어디/누가에 답한다 · 하루 일과의 순서를 안다 |
| 운동 | 한 발로 여러 초 선다 · 몇 개를 잡는다 · 단추를 채운다 · 사람을 그리면 신체 부위 3개 이상 |

### 만 5세
| 영역 | 이정표 |
|------|--------|
| 사회·정서 | **규칙 있는 놀이의 규칙을 따른다** · 노래·춤·연기를 한다 · 도움을 요청한다 |
| 언어 | **여러 문장으로 이야기를 한다** · 대화를 주고받는다 · 이름을 쓰려고 시도한다 |
| 인지 | **10까지 센다** · 자기 이름의 글자를 알아본다 · 시간 개념(오늘/내일)을 안다 |
| 운동 | 한 발로 깡충 뛴다 · 단추를 채운다 · **사람을 그리면 신체 부위 6개 이상** |

## 2. 실행기능 — 이 시기 최우선 투자

### 왜 중요한가
실행기능(Executive Function)은 **작업기억 · 억제 조절 · 인지 유연성**의 세 요소로, 이후 학업 성취·사회적 성공을 강하게 예측합니다. 하버드 아동발달센터가 이 시기 핵심 목표로 제시하는 능력입니다.

### 집에서 기르는 방법 (교구 불필요)

| 능력 | 놀이·활동 |
|------|-----------|
| **억제 조절** | "무궁화꽃이 피었습니다", 얼음땡, 사이먼 가라사대, "반대로 말하기"(내가 크다 하면 너는 작다), 조용히 걷기 시합 |
| **작업기억** | 카드 짝 맞추기(메모리 게임), 3단계 심부름, "시장에 가면~" 누적 게임 |
| **인지 유연성** | 규칙 바꿔가며 분류하기, 같은 물건의 다른 용도 찾기, 보드게임 규칙 변형 |
| **계획·조직** | 요리하기(순서대로), 레고 설명서 보고 만들기, 하루 계획을 그림으로 짜기 |

### 특히 효과적인 것: **규칙 있는 놀이와 극놀이**
- 보드게임(순서 기다리기, 규칙 준수, 지는 것 견디기)
- **역할극**: 아이가 스스로 정한 역할을 유지하는 것 자체가 강력한 자기조절 훈련입니다(Tools of the Mind 프로그램의 핵심 원리). **[보통]**

## 3. 문해력 준비 — 무엇을, 어떤 순서로

초등학교 읽기 능력을 예측하는 요소는 연구가 잘 정리되어 있습니다. **순서가 중요합니다.**

### 우선순위
1. **구어 능력과 어휘** (가장 중요) — 대화, 책 읽기, 설명하기
2. **음운 인식** — 소리를 인식하고 조작하는 능력
3. **글자-소리 대응** — 자모 지식
4. **읽기 유창성** — 초등 이후

### 음운 인식 놀이 (한글의 경우)
- **음절 나누기**: "사·과" 손뼉 치며 나누기 (한국어는 음절 단위가 자연스러워 여기서 시작)
- **첫소리 찾기**: "'ㄱ' 소리로 시작하는 말은?"
- **끝말잇기**, **말 만들기**
- **라임·동요**: 반복되는 소리가 있는 그림책

### 자모 노출 (강요 없이)
- 아이 **이름의 글자**부터. 가장 동기가 높습니다.
- 냉장고 자석 글자, 간판 읽기, 이름표 붙이기
- **쓰기 강요는 하지 않습니다.** 소근육이 준비되지 않은 상태에서 연필 쥐기를 강요하면 잘못된 습관이 생깁니다. 대신 점토, 가위질, 구슬 꿰기로 손 힘을 기릅니다.

### 이 시기 책 읽기
- 하루 **20분 이상**, 여전히 소리 내어 읽어줍니다. 아이가 혼자 읽게 되어도 계속하세요.
- **이야기 구조 질문**: "처음에 무슨 일이 있었지? 그래서 어떻게 됐어? 마지막엔?"
- **추론 질문**: "왜 그랬을까?", "다음에 어떻게 될 것 같아?"
- **글 없는 그림책**으로 아이가 이야기를 지어내게 합니다 — 표현 언어에 매우 효과적.

## 4. 사회성 · 또래 갈등

### 발달 양상
- 4세: 우정이 생기지만 매우 유동적. "너랑 안 놀아"는 흔하고 심각하지 않습니다.
- 5세: 규칙과 공정성에 민감해집니다. "그건 반칙이야"가 자주 나옵니다.
- **마음이론(Theory of Mind)**: 4세 전후로 **타인이 나와 다른 생각을 가질 수 있다**는 것을 이해하기 시작합니다. 공감의 인지적 토대입니다.

### 갈등이 생겼을 때 — 부모의 역할은 심판이 아니라 코치
1. **바로 해결해주지 않습니다.** 안전 문제가 아니면 잠시 지켜봅니다.
2. 개입할 때는 **양쪽의 감정을 말로 옮겨줍니다.** "너는 그 차를 갖고 놀고 싶었고, 얘는 아직 다 못 놀았대."
3. **해결책을 아이들에게 묻습니다.** "어떻게 하면 둘 다 놀 수 있을까?"
4. 합의를 실행하도록 도와줍니다.

### 거짓말과 상상
- 4~5세의 거짓말은 **인지 발달의 신호**입니다(타인의 마음을 이해해야 거짓말이 가능). 도덕적 결함이 아닙니다.
- 대응: 함정에 빠뜨리지 않습니다("네가 그랬지?" 대신 "무슨 일이 있었는지 같이 보자").
- 정직을 칭찬합니다. "사실대로 말해줘서 고마워."

## 5. 유치원·기관 선택 기준

과장된 커리큘럼보다 아래를 봅니다. 유아기 교육의 질을 예측하는 것은 **상호작용의 질**입니다.

- [ ] **교사와 아이의 상호작용**: 아이 눈높이에서 대화하는가, 지시만 하는가
- [ ] 교사 대 아동 비율, **교사 이직률**
- [ ] **하루 중 자유놀이 시간**이 충분한가 (학습식으로만 채워져 있지 않은가)
- [ ] **매일 실외 활동**이 있는가
- [ ] 화면 사용 정책
- [ ] 훈육 방침 — 체벌·수치 주기·격리를 쓰지 않는가
- [ ] 급식 · 위생 · 안전 시설
- [ ] 부모와의 소통 방식

> 학습 중심 프로그램이 단기적으로 글자·숫자 성과를 높여도, **장기적으로는 놀이 중심과 차이가 없거나 오히려 사회정서 면에서 불리하다**는 연구들이 있습니다. **[보통]** 커리큘럼의 화려함보다 **교사의 태도**를 보세요.

## 6. 흔한 문제 상황

### 잠들기 거부 / 밤에 무서워하기
- 3~5세는 **상상력이 발달하면서 두려움이 생깁니다.** "괴물 없어"라고 부정하기보다 통제감을 줍니다: 수면등, "괴물 스프레이", 문 열어두기.
- 취침 루틴을 유지하고, **잠들기 1시간 전 화면 금지**.

### 형제 출생에 따른 퇴행
- 배변·말·수면에서 퇴행이 흔합니다. **관심 확보를 위한 정상 반응**입니다.
- 대응: 하루 10~15분 **첫째와 단둘이 보내는 시간**을 고정합니다. 이것이 가장 효과적입니다.
- "형/누나니까 참아"를 쓰지 않습니다.

### 화면 시간 관리
- 만 2~5세: **하루 1시간 이내**의 고품질 콘텐츠, 가능하면 함께 시청
- 정해진 시간·장소만 (예: 주말 오후, 거실에서만)
- **끝내는 규칙을 미리** 정합니다. "이거 하나 끝나면 끄는 거야" — 갑자기 끄면 갈등이 생깁니다.
- 침실·식탁에는 화면을 두지 않습니다.

### "왜?" 질문 폭격
- 4세 무렵 하루 수십~수백 개의 질문이 나옵니다. **인지 발달의 정점**입니다.
- 다 답할 필요 없습니다. **"너는 왜 그럴 것 같아?"**로 되돌려주는 것이 오히려 사고력을 키웁니다.
- 모르면 **"같이 찾아보자"** — 모른다고 인정하는 모습이 좋은 모델입니다.

## 7. 이 시기 준비물

- 보드게임(간단한 규칙, 순서 있는 것), 카드 게임
- 레고·자석 블록·구슬 꿰기 (소근육 + 계획)
- 가위, 풀, 색연필, 스케치북 — **연필보다 굵은 도구부터**
- 자전거(보조바퀴 또는 밸런스 바이크) + **안전모**
- 줄넘기, 공, 훌라후프 (대근육)
- 그림책 + 짧은 챕터북(읽어주기용)
- 아이 키에 맞는 책상·의자 (발이 바닥에 닿는 높이)
- 낮은 옷장·발판 — 스스로 준비하는 환경

**사지 않아도 되는 것**
- 조기 학습지 세트, 영어 전집, 학습 태블릿
- 지능·창의력 향상을 표방하는 고가 교구 — 그런 효과의 근거는 거의 없습니다

## 8. 취학 전 최종 점검 (만 5~6세)

### 학교가 실제로 요구하는 것
- [ ] 30분 정도 앉아서 집중할 수 있다
- [ ] 지시를 듣고 따를 수 있다
- [ ] 화장실을 스스로 이용한다
- [ ] 도움이 필요할 때 어른에게 말할 수 있다
- [ ] 자기 물건을 챙긴다
- [ ] 순서를 기다리고 규칙을 지킨다
- [ ] 좌절해도 어느 정도 진정할 수 있다
- [ ] 자기 이름을 알아보고 쓰려고 시도한다
- [ ] 10까지 세고, 개수와 연결할 수 있다
- [ ] 다른 아이와 협력해서 논다

### 건강 점검
- [ ] **영유아 건강검진 6차(42~48개월), 7차(54~60개월), 8차(66~71개월)**
- [ ] **구강검진 3차(42~53개월), 4차(54~65개월)**
- [ ] **만 4~6세 추가 접종**: DTaP 5차, IPV 4차, MMR 2차 — 취학 전 접종 확인 필수
- [ ] **시력 검사** — 약시는 이 시기에 발견해 치료해야 회복 가능성이 높습니다. 만 3~5세 시력 검진을 반드시 받으세요. **[강함]**
- [ ] 청력 확인
- [ ] 치과 정기 검진 (6개월마다)
