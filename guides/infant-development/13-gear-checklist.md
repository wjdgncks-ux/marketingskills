# 13. 준비물 마스터 체크리스트

원칙 세 가지:
1. **기본값은 "안 산다".** 필요해진 다음에 사도 늦지 않습니다. 대부분 하루면 배송됩니다.
2. **안전 관련 물건에는 돈을 아끼지 않습니다.** 그 외에는 아껴도 됩니다.
3. **아이는 물건이 아니라 부모의 시간과 여유를 필요로 합니다.** 물건에 쓸 돈의 일부를 부모의 수면·식사·도움에 쓰는 것이 더 효율적입니다.

> 대여·중고를 적극 활용하세요. 단 **카시트와 매트리스는 새것**으로 (사고 이력·위생·열화 문제).

---

## 1. 출산 전 (필수)

### 안전 — 타협 없음
| 물건 | 요건 |
|------|------|
| **카시트** | 신생아부터 **뒤보기** 가능. 안전 인증 확인. **미리 차에 장착 연습** |
| **아기 잠자리** | 아기침대 또는 베이시넷. **단단하고 평평한 매트리스** + 딱 맞는 시트 |
| 방수 요/패드 | 매트리스 커버용 2장 |
| 시트 | 잠자리에 딱 맞는 것 2~3장 (여벌 필수) |
| **수면조끼** | 이불 대신. 계절에 맞는 TOG |

### 수유
- 수유쿠션 (있으면 편함)
- 젖병 2~3개 + 신생아용 젖꼭지 (완모 예정이어도 1~2개는 준비)
- 젖병 세척솔, 소독 방법(열탕 또는 소독기)
- 분유 1통 (만일에 대비 — 모유가 늦게 나오는 경우가 흔합니다)
- 수유패드, 유두 보호크림
- (필요 시) 유축기 — **대여부터 고려**

### 기저귀·목욕
- 신생아용 기저귀 1팩 (**대량 구매 금지** — 금방 사이즈가 바뀌고, 맞지 않을 수 있음)
- 물티슈
- 기저귀 갈이 매트
- 아기 욕조 + 목욕 지지대
- 순한 아기 세정제, 보습제
- 가제 수건 10장 이상, 목욕 타월 2장
- 손톱가위 또는 손톱 갈이
- **코 흡입기** (감기 때 필수)
- 체온계 — 비접촉식 + **직장/구강 겸용 1개** (3개월 미만은 직장 체온이 기준)

### 의류 (계절 고려, 적게)
- 배냇저고리·바디수트 5~7벌
- 우주복 2~3벌
- 속싸개 2~3장 (**뒤집기 시작 시 중단**)
- 손싸개, 모자, 양말
- **신생아 신발은 필요 없습니다**

### 기타
- 아기 세제 (성인 세제와 분리)
- 젖병 건조대
- 기저귀 처리용 휴지통
- 수유등 (밝지 않은 조명)
- 그림책 5권 (헝겊책·보드북)

---

## 2. 있으면 좋은 것 (필수는 아님)

- 유모차 — **아이를 본 뒤에 사도 됩니다.** 생활 반경(엘리베이터·대중교통·차 트렁크)에 맞춰 고르세요
- 아기띠 — 신생아 지지 가능 여부, **M자 자세** 확인
- 백색소음기 (**아기 머리에서 떨어뜨려 낮은 볼륨**으로)
- 바운서 / 아기 체육관 (**장시간 두지 않기**)
- 젖병 소독기, 분유 제조기
- 기저귀 가방
- 수유 조명, 아기 모니터

---

## 3. 사지 않아도 되는 것 (또는 사면 안 되는 것)

### 사면 안 되는 것 — 안전 문제
| 물건 | 이유 |
|------|------|
| **보행기(walker)** | 낙상 위험, 걷기 지연. AAP 사용 금지 권고 |
| **아기침대 범퍼** | 질식·교살 위험 |
| **수면 포지셔너 / 경사형 수면기구** | 질식 위험. 여러 국가에서 리콜 이력 |
| **이앓이 목걸이(호박 등)** | 교살·질식 위험 |
| 아기 베개 (만 1세 미만) | 질식 위험 |
| 중고 카시트 | 사고 이력·유효기간 확인 불가 |
| SIDS 예방을 표방하는 웨어러블 모니터 | 의학적 근거 없음. 잘못된 안심을 줌 |

### 굳이 필요 없는 것 — 돈 낭비
- 신생아 신발 · 손목 딸랑이 · 흑백 모빌 세트(**부모 얼굴이 최고의 자극**)
- 젖병 소독기(열탕으로 충분) · 분유 제조기 · 물티슈 워머
- 기저귀 전용 쓰레기통(전용 리필 비용이 큼)
- 유아용 전용 세탁기
- 대형 놀이매트 세트(작은 것으로 시작)
- **전자 학습 교구 · 플래시카드 · 한글/영어 조기교육 전집**
- 고가의 두뇌개발 교구 — 근거 없음
- 브랜드 아기 옷 다수 — 금방 작아지고 대부분 선물로 들어옵니다

## 4. 시기별 추가 준비물

### 4~6개월
- [ ] 이유식 의자 (**5점식 안전벨트**, 발 받침 있는 것)
- [ ] 실리콘 숟가락, 흡착 그릇, 소매 있는 방수 턱받이
- [ ] 치발기 (냉장 가능)
- [ ] **아기 칫솔 + 불소 치약** (첫니 나면 즉시)
- [ ] 이유식 조리도구 (기존 도구로도 충분)
- [ ] 빨대컵 또는 오픈컵

### 7~12개월
- [ ] **안전용품 일체** — 콘센트 커버, 서랍 잠금, 안전문, **가구 벽 고정 브래킷**, 모서리 보호대
- [ ] 놀이매트
- [ ] 큰 블록, 넣기/빼기 장난감, 공
- [ ] 밀기 장난감(푸시 카트) — 보행기 아님
- [ ] 목욕 장난감, 욕조 미끄럼 방지 매트
- [ ] 실외용 신발 (걷기 시작 후)

### 13~24개월
- [ ] 굵은 크레용, 큰 도화지, 세척 가능한 물감
- [ ] 3~6조각 퍼즐, 모양 맞추기
- [ ] 라이드온(타는 장난감), 공
- [ ] 유아 식기(포크·숟가락), 미끄럼 방지 컵
- [ ] **낮은 책장** (표지가 보이게 꽂는 형태)
- [ ] 유아 변기 또는 변기 커버 + 발판 (준비 신호 관찰 후)
- [ ] 안전모 (자전거·킥보드 시작 시)

### 24~36개월
- [ ] 역할놀이 소품 (주방·병원·인형)
- [ ] 나무/자석 블록, 4~12조각 퍼즐
- [ ] 세발자전거 또는 밸런스 바이크
- [ ] 안전 가위, 풀, 색종이
- [ ] 팬티 여러 장, 방수 매트리스 커버
- [ ] 낮은 옷걸이·발판 (스스로 하기 환경)

### 만 3~5세
- [ ] 보드게임, 카드게임
- [ ] 레고, 구슬 꿰기
- [ ] 자전거 + 안전모
- [ ] 아이 키에 맞는 책상·의자 (**발이 바닥에 닿는 높이**)
- [ ] 줄넘기, 공 등 실외 놀이도구
- [ ] 스케치북, 색연필, 사인펜

## 5. 소모품 구매 전략

| 품목 | 전략 |
|------|------|
| 기저귀 | **한 번에 소량.** 사이즈 변화가 빠르고 브랜드가 안 맞을 수 있음 |
| 물티슈 | 대량 구매 무난 (오래 씀) |
| 분유 | 브랜드 변경 가능성 있으므로 소량부터 |
| 옷 | **선물로 들어옵니다.** 출산 후에 부족한 것만 |
| 장난감 | 순환(rotation) 전략 — 많이 사지 말고 몇 개를 돌려가며 |

---

## 6. 돈을 어디에 쓸 것인가 — 우선순위

```
1순위  안전         카시트, 안전한 잠자리, 가구 고정, 안전문
2순위  부모의 회복   산후도우미, 식사 배달, 가사도우미, 조리원
3순위  책           그림책은 아깝지 않은 유일한 '교육' 지출
4순위  이동          유모차, 아기띠
5순위  기타          장난감, 옷, 인테리어
```

> **부모가 잠을 자고 밥을 먹는 것이, 아이에게 어떤 교구보다 도움이 됩니다.** 산후 첫 6주의 도우미 비용은 교육비로 생각하세요.

---

## 7. 출산 선물 받을 때 요청하면 좋은 것

주변에서 무엇을 선물할지 물어볼 때 유용합니다.
- **그림책** (중복돼도 좋습니다)
- 기저귀·물티슈 (실용적)
- **식사 배달 / 밀키트 기프티콘** — 산후 초기에 가장 도움이 됩니다
- 청소 서비스 이용권
- 다음 사이즈 옷 (신생아 옷은 이미 넘칩니다)
