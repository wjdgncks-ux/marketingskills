# 15. 부모 돌보기 — 이것도 아이 발달의 일부입니다

부모의 정신건강은 감성적인 주제가 아니라 **아이 발달의 직접적 변수**입니다. 산모의 우울은 아이의 언어·인지·정서 발달 지연과 연관되며, **치료하면 아이의 결과도 개선됩니다.** **[강함]** 이 문서를 "여유가 있으면 챙기는 것"이 아니라 **필수 항목**으로 다루세요.

---

## 1. 산후우울 — 알아보고, 치료하는 것

### 베이비 블루스 vs 산후우울증

| | 베이비 블루스 | 산후우울증 |
|---|---|---|
| 빈도 | 산모의 **50~80%** | 산모의 **약 10~15%** |
| 시작 | 출산 후 2~3일 | 언제든 (출산 후 1년 이내) |
| 기간 | **2주 이내 호전** | 2주 이상 지속·악화 |
| 증상 | 눈물, 기분 변화, 예민함 | 지속적 우울, 무가치감, 아이에 대한 무감정, 불면(아이가 자도 못 잠), 식욕 변화, 죄책감 |
| 조치 | 휴식·지지 | **치료 필요** |

> **2주가 기준입니다.** 2주 넘게 지속되면 반드시 진료를 받으세요.

### 아빠도 겪습니다
배우자의 산후 우울은 상당한 비율(연구에 따라 약 10% 내외)에서 보고됩니다. 남성은 우울감보다 **짜증·분노·회피·과로·음주**로 나타나는 경우가 많아 놓치기 쉽습니다.

### 자가 점검 (EPDS 기반 요약)
에든버러 산후우울척도(EPDS)는 10문항의 검증된 자가 도구입니다. 아래는 핵심을 요약한 것으로, **정식 검사를 대체하지 않습니다.**

지난 7일 동안:
1. 웃을 수 있었고 재미있는 것을 재미있게 느꼈다
2. 앞으로의 일을 기대하며 즐거워했다
3. 일이 잘못되면 필요 이상으로 나를 탓했다
4. 뚜렷한 이유 없이 불안하거나 걱정스러웠다
5. 뚜렷한 이유 없이 무섭거나 두려웠다
6. 일이 감당하기 어렵게 느껴졌다
7. 너무 불행해서 잠을 잘 못 잤다
8. 슬프거나 비참하게 느꼈다
9. 너무 불행해서 울었다
10. **나 자신을 해치는 생각이 들었다**

- 국내외에서 통상 **총점 10점 이상(또는 13점 이상)**을 추가 평가 기준으로 사용합니다.
- **10번 문항에 해당한다면 점수와 무관하게 즉시 도움을 구하세요.**

### 도움받는 곳
- **산부인과 / 정신건강의학과** — 수유 중에도 사용 가능한 약물이 있습니다. 진료를 미루지 마세요
- **정신건강복지센터** (지역별, 무료 상담)
- **정신건강 위기상담전화 1577-0199** (24시간)
- **자살예방상담전화 109**
- 영유아 건강검진 1차·2차 문진표에도 산모 우울 관련 문항이 포함되어 있습니다 — **솔직하게 답하세요**

### 즉시 도움이 필요한 신호
- 자신이나 아이를 해치고 싶은 생각
- 현실감이 없거나 이상한 생각·환각 (**산후 정신병은 응급입니다 — 즉시 응급실**)
- 아이를 돌볼 수 없다고 느낌
- 며칠간 먹지도 자지도 못함

## 2. 수면 — 가장 먼저 무너지고, 가장 먼저 챙겨야 하는 것

만성 수면 부족은 판단력·감정 조절·면역을 직접 손상시킵니다. **육아 갈등의 상당 부분은 실제로는 수면 부족 문제입니다.**

### 전략
1. **연속 수면 확보**: 조각난 8시간보다 **연속 4~5시간**이 회복에 유리합니다. 교대로 "off 시간"을 만드세요
2. **낮잠 죄책감 없애기**: 아이가 잘 때 집안일 대신 **자는 것**이 우선입니다
3. **야간 담당 분담** — 모유수유 중이라도 기저귀·트림·재우기는 비수유자가
4. **주말 교대 늦잠**: 각자 주 1회는 아침에 3~4시간 더 자기
5. 도움을 받을 수 있다면 **밤 시간대에** 받으세요 (낮 도움보다 효과가 큽니다)

## 3. 부부 관계 — 가장 흔한 붕괴 지점

### 알려진 사실
Gottman 등의 종단연구에서, **첫 아이 출생 후 상당수의 부부가 관계 만족도 하락을 경험**합니다. 예외는 대부분 **역할 분담과 대화 방식을 미리 정한 부부**였습니다.

### 갈등을 줄이는 실전 규칙

**① "도와준다"는 말을 없애기**
육아는 한 사람의 일이 아닙니다. **각자 완전히 담당하는 영역**을 나눕니다 — 실행뿐 아니라 **기억하고 계획하는 것(정신적 부하)까지** 포함해서.

예시 분담표:
| 영역 | 담당 |
|------|------|
| 예방접종·검진 일정 관리 및 예약 | |
| 기저귀·분유 재고 관리 및 주문 | |
| 목욕 | |
| 야간 담당 (요일/시간대) | |
| 병원 동행 | |
| 어린이집 준비물·연락 | |
| 식사 준비 | |
| 청소·빨래 | |

**② 주 15분 '점검 대화'**
- 잘 되고 있는 것 1개, 바꾸고 싶은 것 1개, 다음 주 일정 확인
- 아이가 자는 시간, 화면 끄고, 정해진 요일에

**③ 비난이 아니라 요청으로**
- ❌ "당신은 아무것도 안 해"
- ✅ "이번 주는 밤에 너무 못 잤어. 목요일 밤은 당신이 맡아줄 수 있어?"

**④ 각자의 회복 시간 보장**
- 주 1회, 2~3시간씩 **혼자만의 시간**을 서로 보장합니다. 이것은 사치가 아니라 지속 가능성의 문제입니다

**⑤ 조부모·친척과의 경계**
- 육아 방식(수면·수유·훈육)에 대한 갈등은 흔합니다
- **결정은 부모가 하고, 그 결정을 배우자가 자기 부모에게 전달**합니다 (자기 쪽 가족은 자기가 응대)
- 타협 불가 항목(안전 수면, 카시트, 체벌 금지, 흡연)은 미리 명확히 전달합니다

## 4. 죄책감 관리

### 흔한 죄책감과 현실
| 죄책감 | 현실 |
|--------|------|
| 모유수유를 못 했다 | 분유로 잘 자란 아이가 대다수입니다. 부모의 상태가 더 중요합니다 |
| 화를 냈다 | 완벽한 부모는 없습니다. **회복(사과와 재연결)이 오히려 교육이 됩니다** |
| 일 때문에 함께 있는 시간이 적다 | 시간의 양보다 **함께 있을 때의 질**이 예측력이 높습니다 |
| 어린이집에 일찍 보냈다 | 질 좋은 보육 환경에서 안정 애착은 충분히 형성됩니다 |
| 화면을 보여줬다 | 하루 몇 분이 아이를 망치지 않습니다. 전체 패턴이 중요합니다 |
| 아이가 싫을 때가 있다 | 흔한 감정입니다. 말할 수 있어야 합니다. 지속되면 상담을 받으세요 |

> **"충분히 좋은 부모(good enough parent)"** — Winnicott의 이 개념은 위로가 아니라 이론입니다. 부모의 적절한 불완전함이 아이의 회복탄력성을 만듭니다.

## 5. 번아웃 신호와 대응

### 신호
- 아이의 울음에 분노나 무감각으로 반응
- 아이와 함께 있는 것이 기쁘지 않고 견디는 일이 됨
- 사소한 일에 폭발
- 자신이 나쁜 부모라는 생각이 반복
- 몸이 계속 아픔, 아무것도 즐겁지 않음

### 즉시 할 것
1. **잠**을 최우선으로 확보 (하루라도 연속 6시간)
2. **혼자만의 시간** 2시간 확보
3. **말하기** — 배우자, 친구, 상담
4. **기준 낮추기** — 집이 지저분해도 됩니다. 배달 음식을 먹어도 됩니다
5. **전문가 상담** — 부모 상담은 아이를 위한 개입입니다

### 아이에게 화가 통제되지 않을 때 (즉시 행동)
```
1. 아이를 안전한 곳(아기침대, 방바닥)에 눕힌다
2. 방을 나온다
3. 5~10분 진정한다 — 물 마시기, 심호흡, 세수
4. 돌아간다
```
**잠깐 우는 것은 안전하지만, 흔들거나 때리는 것은 안전하지 않습니다.** 자리를 뜨는 것은 방임이 아니라 안전 조치입니다.
