근거 기반 영유아 발달·양육 실행 매뉴얼 · 0~5세

## 이 책의 두 가지 뼈대

**관통 은유 — 나가는 힘, 돌아올 자리**

부모의 일은 결국 두 가지뿐입니다. 아이가 세상으로 **나가게 하는 것**, 그리고 아이가 **돌아올 자리**가 되는 것. 애착 연구가 말하는 안전기지(secure base)입니다. 이 책의 모든 장은 이 둘 중 하나를 다룹니다.

```
         ┌────── 나갈 때 ──────┐
         │   지켜봐 줘          │
    [돌아올 자리]           [세상]
         │   받아줘             │
         └────── 돌아올 때 ─────┘
```

**시그니처 기술 — 네 박자**

> **멈춤 → 되돌림 → 이름 → 기다림**

0개월부터 5세까지, 이 네 박자가 형태만 바꿔 반복됩니다. 신생아에겐 옹알이 따라 하기, 두 살에겐 감정에 이름 붙이기, 다섯 살에겐 되물어주기. **이 책은 하나의 기술이 자라는 이야기입니다.**

## 이 책을 읽는 세 가지 방법

**① 처음이라면 — 순서대로**
여는 글 → 1부(10p) → 2부(30p)까지만 먼저 읽으세요. 40페이지면 이 책의 전부를 손에 넣습니다. 3부부터는 필요할 때 펼치면 됩니다.

**② 아이가 있다면 — 해당 월령 장 하나만**
3부에서 지금 월령의 장 하나만 펴세요. 각 장은 **「이번 달 딱 3가지」**로 시작합니다. 바쁜 날엔 그 세 줄만 읽어도 됩니다.

**③ 급하다면 — 색인 또는 4부**
아이가 아프면 [4부](part4-ch20-fever.md)로, 뭔가 이상하면 [37장 경고 신호](part7.md)로 바로 가세요.
