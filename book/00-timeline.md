# 첫 5년 타임라인 — 시간순으로 보기

> 이 책 전체를 **시간 순서 하나로 꿰어놓은 지도**입니다.
> 지금 시기의 칸만 보면, 이번 달에 할 일·아이 몸의 일·검진과 접종·살 물건이 한눈에 나옵니다.
> 각 칸의 상세는 **→ 읽을 장**을 펴세요. 일정 전체는 [부록 B](appendix.md)를 달력에 등록하면 끝납니다.

| **미리 정할 것** | 다닐 소아과 · 밤에 갈 병원(달빛어린이병원 검색) · 산후 도움받을 사람 |
| **제도** | 산모·신생아 건강관리 지원은 **예정일 40일 전부터 신청** 가능 |

| ✂️ **붙여둘 것** | 부록 E(응급 양식) 인쇄해 채우기 · 시트 ③(안전 필수 8) |

## 0~3개월 — 생존과 애착

| | |
|---|---|
| 🎯 **딱 3가지** | ① 울면 반응하기(버릇 안 됩니다) ② 배밀이 자세 하루 누적 30분 ③ **부모가 자기** |
| **먹이기** | 하루 8~12회 수유가 정상 · 젖은 기저귀 6개 이상이면 충분히 먹는 것 · 분유는 70℃ 물로 |
| **재우기** | **등을 대고 · 평평한 곳 · 잠자리엔 아무것도 없이** — 이 시기 안전의 전부 |
| **제도** | BCG `4주 이내` · B형간염 2차 `1개월` · **검진 1차 `14~35일`(가장 놓치기 쉬움)** · 출생신고+행복출산 원스톱 `1개월 이내` · 2개월 접종 세트 |
| 📦 **물건** | 더 살 것 없습니다. 교구도 아직 필요 없어요 |
| 🚩 **이 시기 최우선** | **3개월 미만 + 38.0℃ = 즉시 응급실.** 해열제로 지켜보지 않습니다 |
| → **읽을 장** | 11장 · 17장(수유) · 19장(재우기) |

| | |
|---|---|

| **먹이기** | 이유식 시작 신호: 목 가누기·앉기·음식에 관심. **4개월 이전 시작 금지** · 알레르기 음식은 미루지 않기 |
| **재우기** | **뒤집기 시작하면 속싸개 중단** · 밤낮 리듬 만들기(낮엔 밝게, 밤엔 어둡게) |
| **제도** | 4개월 접종 세트 · **검진 2차 `4~6개월` — K-DST(발달평가) 시작** · 6개월 접종 세트 · 인플루엔자 `6개월부터 매년 가을` |
| 📦 **물건** | 이유식 의자(발 받침 있는 것) · 유아 칫솔 · 치발기 |
| 🚩 | 6개월에 눈 맞춤·웃음이 없다 → 검진 때 꼭 말하기 |
