# 5부 · 나를 지킨다

> 부모의 정신건강은 감성적인 주제가 아니라 **아이 발달의 직접적 변수**입니다.
> 산모의 우울은 아이의 언어·인지·정서 발달 지연과 연관되며, **치료하면 아이의 결과도 개선됩니다.** **[강함]**
> 이 부를 "여유가 있으면 챙기는 것"이 아니라 **필수 항목**으로 다루세요.

# 24장 · 산모의 몸 회복

## 출산 후 6주 — 몸에서 일어나는 일

| 항목 | 정상 경과 |
|---|---|
| **오로(산후 질 분비물)** | 붉은색 → 갈색 → 노란빛으로 변하며 **4~6주** 지속 |
| **자궁 수축통(훗배앓이)** | 수유 시 심해짐. 며칠~1주 |
| **회음부 통증** | 열상·절개가 있었다면 2~3주. 냉찜질 → 좌욕 |
| **제왕절개 상처** | 통증 2주 전후, 완전 회복 6주 이상. 무거운 것 들지 않기 |
| **유방 울혈** | 성숙유가 돌 때(2~5일) 단단하고 아픔 |
| **탈모** | 산후 3~6개월에 심해졌다 회복. **정상입니다** |
| **땀·야간 발한** | 호르몬 변화. 몇 주 |

## 회복을 돕는 것

- **골반저근 운동(케겔)**: 가능해지면 시작. 요실금 예방과 회복에 도움 **[보통]**
- **운동 재개**: 걷기는 편해지면 곧, 본격적 운동은 **산후 검진에서 확인 후**(대개 6주). 제왕절개는 더 늦게
- **변비 관리**: 수분·섬유질. 회음부 통증이 있으면 힘주기가 두려워 악화됩니다
- **수분과 식사**: 수유 중에는 추가 열량과 수분이 필요합니다
- **산후 검진**: 대개 출산 4~6주. **꼭 받으세요.** 우울 선별도 여기서 이루어집니다

## 🚩 즉시 진료

- **38℃ 이상의 발열**
- 오로에서 **악취**가 나거나, 갑자기 양이 늘거나 큰 덩어리가 나옴
- **한 시간에 패드 하나를 적실 정도의 출혈**
- 회음부·제왕절개 상처의 발적·고름·벌어짐
- **한쪽 종아리의 통증과 부종** → 혈전 의심
- **심한 두통, 시야 흐림, 상복부 통증** → 산후 전자간증 가능. **출산 후에도 발생할 수 있습니다**
- 숨이 차고 가슴이 아픔
- 유방 통증 + 발열 → 유선염 (17장)

# 25장 · 산후우울

## 베이비 블루스 vs 산후우울증

| | 베이비 블루스 | 산후우울증 |
|---|---|---|
| 빈도 | 산모의 **50~80%** | 산모의 **약 10~15%** |
| 시작 | 출산 후 2~3일 | 언제든 (출산 후 1년 이내) |
| 기간 | **2주 이내 호전** | **2주 이상 지속·악화** |
| 증상 | 눈물, 기분 변화, 예민함 | 지속적 우울, 무가치감, 아이에 대한 무감정, **아이가 자도 못 자는 불면**, 식욕 변화, 죄책감 |
| 조치 | 휴식·지지 | **치료 필요** |

> **2주가 기준입니다.** 2주 넘게 지속되면 반드시 진료를 받으세요.

## 아빠도 겪습니다

배우자의 산후 우울은 상당한 비율(연구에 따라 약 10% 내외)에서 보고됩니다. 남성은 우울감보다 **짜증·분노·회피·과로·음주**로 나타나는 경우가 많아 놓치기 쉽습니다.

## 자가 점검 (EPDS 기반 요약)

에든버러 산후우울척도(EPDS)는 검증된 10문항 자가 도구입니다. 아래는 핵심 요약이며 **정식 검사를 대체하지 않습니다.**

**지난 7일 동안,**
1. 웃을 수 있었고 재미있는 것을 재미있게 느꼈다
2. 앞으로의 일을 기대하며 즐거워했다
3. 일이 잘못되면 필요 이상으로 나를 탓했다
4. 뚜렷한 이유 없이 불안하거나 걱정스러웠다
5. 뚜렷한 이유 없이 무섭거나 두려웠다
6. 일이 감당하기 어렵게 느껴졌다
7. 너무 불행해서 잠을 잘 못 잤다
8. 슬프거나 비참하게 느꼈다
9. 너무 불행해서 울었다
10. **나 자신을 해치는 생각이 들었다**

- 통상 **총점 10점 이상(또는 13점 이상)**을 추가 평가 기준으로 사용합니다
- **10번 문항에 해당한다면 점수와 무관하게 즉시 도움을 구하세요**

## 🚩 즉시 도움이 필요한 신호

- 자신이나 아이를 해치고 싶은 생각
- **현실감이 없거나 이상한 생각·환각** → **산후 정신병은 응급입니다. 즉시 응급실**
- 아이를 돌볼 수 없다고 느낌
- 며칠간 먹지도 자지도 못함

## 도움받는 곳

| 곳 | 내용 |
|---|---|
| 산부인과 / 정신건강의학과 | **수유 중에도 쓸 수 있는 약이 있습니다.** 진료를 미루지 마세요 |
| **정신건강복지센터** (지역별) | 무료 상담 |
| **1577-0199** | 정신건강 위기상담 (24시간) |
| **109** | 자살예방상담 |
| 영유아 건강검진 문진표 | 산모 우울 문항이 포함되어 있습니다 — **솔직하게 답하세요** |

# 26장 · 부부

## 알려진 사실

Gottman 등의 종단연구에서 **첫 아이 출생 후 상당수의 부부가 관계 만족도 하락**을 경험합니다. 예외는 대부분 **역할 분담과 대화 방식을 미리 정한 부부**였습니다.

## ① "도와준다"는 말을 없애기

육아는 한 사람의 일이 아닙니다. **각자 완전히 담당하는 영역**을 나눕니다 — 실행뿐 아니라 **기억하고 계획하는 것(정신적 부하)까지** 포함해서.

> "언제 접종이지?"라고 묻는 것과, **접종 시기를 기억하고 예약까지 하는 것**은 다른 일입니다. 후자를 나눠야 합니다.

### 분담표 (채워서 벽에 붙이세요)

| 영역 | 담당 |
|---|---|
| 예방접종·검진 일정 관리 및 예약 | |
| 기저귀·분유 재고 관리 및 주문 | |
| 목욕 | |
| 야간 담당 (요일/시간대) | |
| 병원 동행 | |
| 어린이집 준비물·연락 | |
| 식사 준비 | |
| 청소·빨래 | |
| 아이 옷 사이즈 확인·구매 | |

## ② 주 15분 점검 대화

- 잘 되고 있는 것 1개, 바꾸고 싶은 것 1개, 다음 주 일정
- 아이가 자는 시간, 화면 끄고, **정해진 요일에**

## ③ 비난이 아니라 요청으로

| ❌ | ✅ |
|---|---|
| "당신은 아무것도 안 해." | "이번 주는 밤에 너무 못 잤어. 목요일 밤은 당신이 맡아줄 수 있어?" |
| "왜 나만 신경 써?" | "접종 일정 관리는 당신이 맡아줬으면 좋겠어." |
| "그렇게 하는 거 아니야." | "나는 이렇게 하고 있어. 방식을 하나로 맞출까?" |

## ④ 각자의 회복 시간 보장

주 1회, 2~3시간씩 **혼자만의 시간**을 서로 보장합니다. **사치가 아니라 지속 가능성의 문제입니다.**

## ⑤ 조부모·친척과의 경계

- 육아 방식(수면·수유·훈육) 갈등은 흔합니다
- **결정은 부모가 하고, 그 결정을 배우자가 자기 부모에게 전달**합니다 (자기 쪽 가족은 자기가 응대)
- **타협 불가 항목**(안전 수면, 카시트, 체벌 금지, 꿀 금지, 흡연)은 미리 명확히. 부록 G 시트를 쓰세요

# 27장 · 죄책감과 번아웃

## 흔한 죄책감과 현실

| 죄책감 | 현실 |
|---|---|
| 모유수유를 못 했다 | 분유로 잘 자란 아이가 대다수입니다. **부모의 상태가 더 중요합니다** |
| 화를 냈다 | 완벽한 부모는 없습니다. **회복(사과와 재연결)이 오히려 교육이 됩니다** |
| 일 때문에 함께 있는 시간이 적다 | 시간의 양보다 **함께 있을 때의 질**이 예측력이 높습니다 |
| 어린이집에 일찍 보냈다 | 질 좋은 보육 환경에서 안정 애착은 충분히 형성됩니다 |
| 화면을 보여줬다 | 하루 몇 분이 아이를 망치지 않습니다. **전체 패턴**이 중요합니다 |
| **아이가 싫을 때가 있다** | 흔한 감정입니다. 말할 수 있어야 합니다. **지속되면 상담을 받으세요** |

> **"충분히 좋은 부모(good enough parent)"** — Winnicott의 이 개념은 위로가 아니라 이론입니다. 부모의 적절한 불완전함이 아이의 회복탄력성을 만듭니다.

## 번아웃 신호

- 아이의 울음에 분노나 **무감각**으로 반응
- 아이와 함께 있는 것이 기쁘지 않고 **견디는 일**이 됨
- 사소한 일에 폭발
- 자신이 나쁜 부모라는 생각이 반복
- 몸이 계속 아픔, 아무것도 즐겁지 않음

## 즉시 할 것

1. **잠**을 최우선으로 (하루라도 연속 6시간)
2. **혼자만의 시간** 2시간 확보
3. **말하기** — 배우자, 친구, 상담
4. **기준 낮추기** — 집이 지저분해도 됩니다. 배달 음식을 먹어도 됩니다
5. **전문가 상담** — 부모 상담은 아이를 위한 개입입니다

## 🚩 아이에게 화가 통제되지 않을 때

```
1. 아이를 안전한 곳(아기침대, 방바닥)에 눕힌다
2. 방을 나온다
3. 5~10분 진정한다 — 물 마시기, 심호흡, 세수
4. 돌아간다
```

**잠깐 우는 것은 안전하지만, 흔들거나 때리는 것은 안전하지 않습니다.** 자리를 뜨는 것은 방임이 아니라 안전 조치입니다.

**이미 소리를 질렀다면 → 회복합니다.**
> "아빠가 아까 큰 소리 내서 미안해. 아빠도 화가 났었어. 그래도 소리 지르는 건 아빠가 잘못한 거야."

## 적응 요령

- **적응에는 보통 2~6주**가 걸립니다. 우는 것이 곧 문제는 아닙니다
- **짧고 일관된 작별 의식.** 몰래 가지 않습니다 (13장)
- **집에서의 예측 가능성**을 유지합니다. 적응기에는 다른 변화(침대 전환, 배변 훈련)를 겹치지 않게
- **익숙한 물건**(애착 인형·이불) 반입 가능 여부 확인

## 모유수유 유지

- 직장에서 **3~4시간마다 유축**
- 보관은 17장 기준
- 사업장 상황을 미리 확인 (수유 공간·시간)

## 죄책감 관리

복직 초기 죄책감은 매우 흔합니다. 근거로 말하면 — **질 좋은 보육 환경에서 안정 애착은 충분히 형성됩니다**(NICHD 대규모 종단연구). 결정적인 것은 함께 있는 시간의 **양이 아니라 반응의 민감성**입니다.

**하루 15분, 화면 없이 아이가 주도하는 놀이 시간**을 고정하는 것이, 두 시간을 흩어 쓰는 것보다 낫습니다.
