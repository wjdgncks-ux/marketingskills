# Ⅰ. 육아 케어 — 먹이고, 재우고, 지키기

## 먹이기

- 신생아는 **하루 8~12회** 수유가 정상. 젖은 기저귀 하루 6개 이상이면 충분히 먹는 것 **[강함]**
- 분유는 **70℃ 이상 물**로 조제 후 식히기 **[강함]** · 남은 분유는 버리기
- 이유식은 **6개월경, 철분 많은 것부터**. 4개월 이전 시작 금지 **[강함]**
- **알레르기 음식(달걀·땅콩 등)은 미루지 않고 이유식 초기에 도입** — 미루면 오히려 위험 증가 **[강함]** (중증 아토피는 의사와 먼저 상의)
- **만 1세 전 꿀 금지**(영아 보툴리눔) **[강함]** · 젖병 물고 재우지 않기(젖병 우식) **[강함]**
- 편식은 유아기 정상 발달. 새 음식은 **10번 이상** 노출 · **얼마나 먹을지는 아이가 정한다** **[보통]**

## 재우기

- **만 1세까지: 등을 대고, 평평한 곳에, 잠자리엔 아무것도 두지 않기** — 영아돌연사 예방의 전부 **[강함]**
- 뒤집기 시작하면 속싸개 중단 **[강함]**
- 수면 퇴행(4·8·12·18개월)은 발달의 신호이며 **지나갑니다**
- 낮잠 전환: 2회→1회는 대개 15~18개월 · "통잠"의 기준은 집집마다 달라도 됩니다

## 지키기 (안전)

- **카시트 — 뒤보기, 뒷좌석, 외투 벗기고. 예외 없음** **[강함]**
- 화장지 심을 통과하는 물건은 전부 치우기 · 포도·방울토마토는 세로 4등분
- **버튼형 전지·자석 구슬 삼킴 = 무증상이어도 즉시 응급실** **[강함]**
- 가구·TV 벽 고정 · 창문 잠금 · 보행기 쓰지 않기 **[강함]**
- 말로 막지 말고 **환경으로 막는다** — 안전이 확보된 공간에서 아이는 더 자유롭게 탐색합니다

## 아플 때 — 판단의 뼈대

- **생후 3개월 미만 + 38.0℃ 이상 = 즉시 응급실.** 해열제로 지켜보지 않습니다 **[강함]**
- 6개월 이후엔 **열 수치보다 아이 상태** — 열이 내렸을 때 노는가?
- 해열제는 **나이가 아니라 체중 기준** · 계량기 사용 · 먹인 시각 메모
- 장염엔 **경구수액(ORS)**. 이온음료는 대체가 아닙니다 **[강함]**
- 감기는 **연간 6~8회가 정상** · 항생제는 바이러스에 듣지 않습니다 **[강함]**
- 판단이 서지 않으면 **가는 쪽을 고르세요**

## 확인 시스템

- **영유아 건강검진 12회(일반 8+구강 4)는 무료 발견 시스템** — 부록 B를 달력에 등록
- 예방접종은 **예방접종도우미(nip.kdca.go.kr)에 자녀 등록**하면 자동 관리
- 18·24개월 검진에서 **M-CHAT(자폐 선별) 요청** · 만 3~5세 **시력검사**(약시 골든타임)

→ 본편 8장 · 4부(17~23장) · 6부

# Ⅱ. 행동 교정 — 훈육과 감정

## 대원칙 세 줄

1. **감정은 모두 허용, 행동은 일부 제한.**
2. **체벌과 고함은 효과가 없고 해롭다** — 행동을 고치지 못하고 공격성만 늘립니다 **[강함]**
3. 훈육의 순서는 **예방 → 연결 → 제한 → 대안 → 회복.** 벌이 아니라 가르치기입니다.

## 떼쓰기 앞에서

- 떼쓰는 중에는 **말을 줄이고 곁에 있기.** 긴 설명은 불에 기름입니다
- 한 문장이면 충분: **"화났구나. 아빠(엄마) 여기 있어."**
- 떼쓰기의 **절반은 배고픔과 졸림**입니다 — 행동 교정 전에 일과부터
- 잠잠해진 **뒤에** 가르칩니다. 폭풍 속 교육은 들리지 않아요

## 말 바꿔 쓰기 (2단 대비)

| ❌ 이렇게 말하면 | ✅ 이렇게 말하면 |
|---|---|
| "그만 울어!" | "속상했구나. 다 울면 이야기하자." |
| "안 돼!" (하루 종일) | "이건 안 되고, **이거나 이거**는 돼." |
| "착하다~" (결과 칭찬) | "끝까지 해냈네." (**과정** 칭찬) |
| "왜 그랬어!" | "무슨 일이 있었는지 말해줄래?" |

## 부모가 화날 때

- 아이를 **안전한 곳에 두고 방을 나오기 → 10분 → 돌아가기.** 잠깐 우는 건 안전합니다. 흔드는 건 아닙니다
- 소리를 질렀다면 → **사과합니다.** 회복이 관계를 만듭니다. 완벽한 부모가 아니라요

## 고치려 하지 않아도 되는 것

손가락 빨기 · 애착 인형 · 일시적 말더듬(2~5세) · 유아 자위 행동 · 눈 깜빡임 같은 일시적 틱 — **대부분 정상 발달이며, 지적하지 않는 것이 대응입니다.** (지속·악화 기준은 본편 39장)

→ 본편 6장(감정 코칭) · 7장(훈육) · 39장

# Ⅲ. 인지와 학습

## 기술은 하나 — 네 박자

> **멈춤 → 되돌림 → 이름 → 기다림(5초)** · 하루 스무 번이면 충분 **[강함]**

| 시기 | 이렇게 |
|---|---|
| 0~3개월 | "아~" 하면 똑같이 "아~" 되돌려주기 |
| 7~12개월 | 가리키면 그쪽을 보고 "비행기!" |
| 13~24개월 | "차!" → "빨간 차!" (한 단어 더) |
| 24~36개월 | "블록이 무너져서 화났구나" (감정에 이름) |
| 만 3~5세 | "왜 밤이 와?" → "너는 왜 그럴 것 같아?" (되물어주기) |

따로 시간 내지 마세요. **기저귀 갈 때, 먹일 때, 목욕할 때** 얹으면 됩니다.

## 언어와 책

- 발달을 가장 크게 움직이는 변수는 교구가 아니라 **부모와 주고받는 대화의 왕복 횟수** **[강함]**
- 매일 책 5~10분. **다 읽을 필요 없습니다** — 그림 하나 짚고 "곰이네, 곰" 이면 충분
- 말하고 **5초 기다리기** — 이 책에서 가장 자주 반복되는 지시

## 화면

- **만 2세 미만: 영상통화 외 보여주지 않기** **[강함]**
- 이후 **하루 1시간 이내 + 가능하면 함께 보기** · 식사·잠자리 전엔 끄기

## 조기교육에 대한 결론

- **만 5세 이전 문자·연산 선행학습의 장기적 이점은 확인되지 않았습니다** **[보통]**
- 초등 성취를 가장 잘 예측하는 것은 **어휘력과 자기조절력**입니다
- 자기조절은 학습지가 아니라 **놀이**로 자랍니다 — 얼음땡·무궁화꽃(억제 조절) · 역할놀이(관점) · 보드게임(순서와 지는 연습)
- "지금 안 하면 늦는다"는 말에는 대개 **파는 물건**이 붙어 있습니다

## 이정표를 읽는 법

- 이 책의 이정표는 **"넷 중 셋이 하는 것"**(75백분위) 기준 — **하나 늦다고 문제가 아닙니다**
- 다만 **12개월 가리키기 없음 · 18개월 단어 없음 · 24개월 두 단어 조합 없음**은 확인이 필요한 신호 → 검진 때 말하기
